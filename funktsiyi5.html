Перетворення графіків

Знаючи графік y = f(x), можна побудувати графік складнішої функції за допомогою геометричних перетворень — без таблиці значень і обчислень:

ПеретворенняЩо відбуваєтьсяНапрямок
y = f(x) + cЗсув по вертикаліc > 0: вгору   c < 0: вниз
y = f(x + c)Зсув по горизонталіЗнак протилежний! c > 0: вліво   c < 0: вправо
y = −f(x)Відображення відносно OXГрафік перевертається вертикально
y = f(−x)Відображення відносно OYГрафік відзеркалюється горизонтально
y = a·f(x)Розтяг/стиск по вертикалі|a| > 1: розтяг   0 < |a| < 1: стиск
y = f(a·x)Стиск/розтяг по горизонталіПротилежно! |a| > 1: стиск   0 < |a| < 1: розтяг
y = |f(x)|Модуль від yВсе, що нижче OX, — відображається вгору
y = f(|x|)Модуль від xПрава частина графіка копіюється дзеркально вліво

Порядок перетворень (коли є кілька одночасно):
1. Горизонтальні зсуви (те, що всередині дужок)
2. Стиски/розтяги по горизонталі
3. Відображення по горизонталі
4. Вертикальні стиски/розтяги
5. Вертикальні зсуви (те, що додається ззовні)

Приклад. Побудувати y = 2·sin(x − π/4) + 1, знаючи y = sin x:

  1. sin(x − π/4) — зсув вправо на π/4
  2. 2·sin(x − π/4) — розтяг по вертикалі вдвічі (амплітуда стає 2)
  3. 2·sin(x − π/4) + 1 — зсув вгору на 1

Типові помилки — зведення

1. ОДЗ: плутають ≥ (корінь) і > (логарифм).

2. Парність: перевіряють f(−x), не перевіривши, чи D(f) симетрична.

3. Зсув y = f(x + c): знак протилежний! f(x + 2) — вліво, не вправо.

4. Показникова: bˣ завжди > 0, рівняння bˣ = (від'ємне) — розв'язків немає.

5. Тригонометрія: період y = sin(ωx) дорівнює 2π/|ω|, а не 2π.

Головне — розуміти, що робить кожен параметр. Тоді формула перестає бути набором символів і стає описом графіка.
