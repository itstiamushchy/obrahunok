ЧАСТИНА 1. ПОНЯТТЯ ВЕКТОРА

Вектор — це величина, яка має не тільки розмір, а й напрямок. Сила, швидкість, переміщення — все це вектори. У математиці вектори дозволяють записувати геометричні задачі через координати і розв'язувати їх алгебраїчно: замість побудов — обчислення.

1. Що таке вектор?

Вектор — направлений відрізок: він має довжину (модуль) і напрямок. Позначення: a→ або AB→ (від точки A до точки B).

Модуль вектора |a→|Довжина вектора. Завжди ≥ 0. Нульовий вектор: |0→| = 0
Рівні векториОднакові довжина і напрямок. Не залежать від місця прикладання
Протилежні векториОднакова довжина, протилежний напрямок: a→ і −a→
Колінеарні векториПаралельні або лежать на одній прямій (однаковий або протилежний напрямок)
Одиничний вектор (орт)Вектор з модулем 1: |e→| = 1. Показує тільки напрямок

2. Координатне подання вектора

У прямокутній системі координат вектор AB→ задається координатами:

AB→ = (x_B − x_A; y_B − y_A) або a→ = (aₓ; a_y)

|a→| = √(aₓ² + a_y²) — модуль вектора

Приклад: A(1;3), B(4;7)

AB→ = (4−1; 7−3) = (3; 4)
|AB→| = √(9+16) = √25 = 5

Що означає (3; 4)? Від точки A до точки B потрібно пройти 3 одиниці вправо і 4 одиниці вгору. Координати вектора — це «інструкція переміщення».

ЧАСТИНА 2. ДІЇ З ВЕКТОРАМИ

3. Додавання і віднімання векторів

Додавання (правило трикутника)a→ + b→: прикладаємо початок b→ до кінця a→, результат — від початку a→ до кінця b→
Правило паралелограмаa→ + b→: будуємо паралелограм на a→ і b→ — діагональ = сума
Координатноa→ + b→ = (aₓ+bₓ; a_y+b_y)
a→ − b→ = (aₓ−bₓ; a_y−b_y)
Властивостіa→+b→ = b→+a→ (комутативність)
(a→+b→)+c→ = a→+(b→+c→) (асоціативність)
a→+0→ = a→

4. Множення вектора на число

λa→ = (λaₓ; λa_y), |λa→| = |λ|·|a→|

λ > 0Однаковий напрямок, довжина множиться на λ
λ < 0Протилежний напрямок, довжина множиться на |λ|
λ = 0Результат — нульовий вектор 0→
Орт вектораe→ = a→/|a→| (одиничний вектор у напрямку a→)

ЧАСТИНА 3. СКАЛЯРНИЙ ДОБУТОК

5. Визначення та формули

Скалярний добуток двох ненульових векторів — число (скаляр), а не вектор:

Навіщо це потрібно? Скалярний добуток відповідає на три питання: 1) який кут між векторами? 2) чи перпендикулярні вони? 3) яка проекція одного вектора на інший? У фізиці — це робота сили: A = F→ · s→.

a→ · b→ = |a→| · |b→| · cos φ

де φ — кут між векторами (0 ≤ φ ≤ π)

Через координати:

a→ · b→ = aₓ·bₓ + a_y·b_y (у площині)

a→ · b→ = aₓ·bₓ + a_y·b_y + a_z·b_z (у просторі)

Перпендикулярністьa→ ⊥ b→ ⟺ a→·b→ = 0 (cos90° = 0)
Паралельність|a→·b→| = |a→|·|b→| (cos0° = 1 або cos180° = −1)
Кут між векторамиcos φ = (a→·b→) / (|a→|·|b→|)
Квадрат вектораa→·a→ = |a→|² скалярний квадрат

Приклад: a→=(2;3), b→=(4;−1)

a→·b→ = 2·4 + 3·(−1) = 8−3 = 5
|a→| = √13 ≈ 3.61; |b→| = √17 ≈ 4.12
cos φ = 5/(√13·√17) = 5/√221 ≈ 5/14.87 ≈ 0.336 → φ ≈ 70.3°

Перевірка: скалярний добуток додатний (= 5) → кут гострий (менше 90°). cos φ ≈ 0.34 — між 0 і 1 → дійсно гострий ✓

Швидка перевірка знака:
a→ · b→ > 0 → кут гострий (φ < 90°)
a→ · b→ = 0 → прямий кут (φ = 90°, вектори перпендикулярні)
a→ · b→ < 0 → кут тупий (φ > 90°)

ЧАСТИНА 4. ВЕКТОРНИЙ ДОБУТОК

6. Векторний добуток (у просторі)

Векторний добуток a→ × b→ — вектор, перпендикулярний до площини a→ і b→:

[a→ × b→] = (a_y·b_z − a_z·b_y; a_z·b_x − a_x·b_z; a_x·b_y − a_y·b_x)

|a→ × b→| = |a→|·|b→|·sin φ

НапрямокПравило правої руки: пальці від a→ до b→, великий палець — напрямок [a→×b→]
Паралельність[a→×b→] = 0→ ⟺ a→ ∥ b→ (sin0° = 0)
Площа паралелограмаS = |[a→×b→]| де a→, b→ — сторони паралелограма
Площа трикутникаS = ½|[a→×b→]|

Типові помилки

1. Плутають координати точки і вектора.
Точка A(1; 3) — це позиція. Вектор AB→ = (3; 4) — це переміщення (різниця координат кінця і початку). Вектор не залежить від місця, точка — залежить.

2. Забувають порядок віднімання при знаходженні координат вектора.
AB→ = (x_B − x_A; y_B − y_A) — кінець мінус початок! BA→ = (x_A − x_B; y_A − y_B) — протилежний вектор. Порядок важливий: AB→ ≠ BA→.

3. Плутають скалярний і векторний добуток.
Скалярний a→·b→ = число (через cos φ). Векторний a→×b→ = вектор (через sin φ). На площині використовують переважно скалярний.

4. Перевіряють перпендикулярність через координати неправильно.
a→ ⊥ b→ ⟺ aₓ·bₓ + a_y·b_y = 0, а не aₓ·bₓ = a_y·b_y. Потрібна сума добутків = 0, не рівність добутків.
