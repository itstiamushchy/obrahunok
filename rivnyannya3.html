ЧАСТИНА 3. КВАДРАТНІ РІВНЯННЯ

Квадратне рівняння — найважливіший тип після лінійного. Воно з'являється скрізь: траєкторія м'яча, площа ділянки, задачі на прибуток. Є 4 методи розв'язання — не потрібно вчити всі, достатньо навчитись обирати правильний за виглядом рівняння.

Як обрати метод за виглядом рівняння:

Немає b (ax² + c = 0) → виражаємо x², беремо ±√

Немає c (ax² + bx = 0) → виносимо x за дужки (НЕ скорочувати на x!)

Коефіцієнти невеликі, a = 1 → Вієт (підбір двох чисел за сумою і добутком)

Загальний випадок → дискримінант (працює ЗАВЖДИ, найуніверсальніший)

Ліва частина розкладається на множники → прирівнюємо кожен до нуля

4. Квадратне рівняння — загальний вигляд

ax² + bx + c = 0, де a ≠ 0. Число a — старший коефіцієнт, b — середній, c — вільний член.

5. Розв'язання через дискримінант

D = b² − 4ac

Що означає D? Дискримінант визначає, скільки разів парабола y = ax² + bx + c перетинає вісь x. D > 0 — двічі (два корені), D = 0 — торкається один раз (один корінь), D < 0 — не перетинає взагалі (коренів немає).

D > 0Два різні дійсні корені:
x₁ = (−b + √D) / 2a
x₂ = (−b − √D) / 2a
D = 0Один корінь (два рівні):
x₁ = x₂ = −b / 2a
D < 0Дійсних коренів немає (∅). Рівняння не має розв'язків у ℝ.

Приклад: 2x² − 5x + 3 = 0

a=2, b=−5, c=3

D = (−5)² − 4·2·3 = 25 − 24 = 1

x₁ = (5 + 1)/4 = 6/4 = 3/2 x₂ = (5 − 1)/4 = 4/4 = 1

Відповідь: x₁ = 1,5; x₂ = 1

Перевірка за Вієтом: x₁ + x₂ = 1,5 + 1 = 2,5 = −b/a = 5/2 ✓. x₁ · x₂ = 1,5 · 1 = 1,5 = c/a = 3/2 ✓

6. Формули Вієта

Для зведеного квадратного рівняння x² + px + q = 0 (a=1) корені x₁ і x₂ пов'язані з коефіцієнтами:

x₁ + x₂ = −p та x₁ · x₂ = q

Навіщо потрібні формули Вієта?

Дозволяють підібрати корені для нескладних рівнянь без обчислення дискримінанта, а також перевірити відповідь.

Коли використовувати: працює швидко при невеликих коефіцієнтах і цілих коренях. Якщо не підібрали за 30 секунд — беріть дискримінант, він працює завжди.

Приклад: x² − 5x + 6 = 0

p = −5, q = 6. Шукаємо два числа, сума яких = 5, добуток = 6.

2 + 3 = 5 ✓ 2 · 3 = 6 ✓ → x₁ = 2, x₂ = 3

7. Неповні квадратні рівняння

ax² = 0x = 0 (єдиний корінь)
ax² + c = 0
(b = 0)		x² = −c/a
• Якщо −c/a > 0: x = ±√(−c/a)
• Якщо −c/a = 0: x = 0
• Якщо −c/a < 0: коренів немає
ax² + bx = 0
(c = 0)		Виносимо x за дужки: x(ax + b) = 0
→ x₁ = 0 або x₂ = −b/a

⚠ Попередження

Ніколи не скорочуйте на x! Якщо поділити обидві частини на x, ви втратите корінь x = 0. Правильно: виносимо x за дужки і прирівнюємо кожен множник до нуля.

8. Розкладання на множники — метод

Якщо ліву частину рівняння вдається розкласти на множники, використовуємо властивість: добуток = 0, якщо хоча б один множник = 0

A · B = 0 ⟺ A = 0 або B = 0

Чому це працює? Добуток двох чисел дорівнює нулю тільки якщо хоча б одне з них — нуль. 5·0 = 0, 0·7 = 0, але 3·4 = 12 ≠ 0. Тому прирівнюємо кожен множник до нуля окремо.

Приклад: x² − 7x + 12 = 0

(x − 3)(x − 4) = 0 [розкладаємо на множники за формулами Вієта]

x − 3 = 0 або x − 4 = 0

x₁ = 3, x₂ = 4

Завжди перевіряйте! Підставте кожен корінь у початкове рівняння. Це захищає від помилок в обчисленнях і від сторонніх коренів. Наприклад: x = 3 → 9 − 21 + 12 = 0 ✓. x = 4 → 16 − 28 + 12 = 0 ✓
