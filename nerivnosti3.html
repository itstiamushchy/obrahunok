Лінійні та квадратні нерівності

ЧАСТИНА 3. КВАДРАТНІ НЕРІВНОСТІ

Квадратна нерівність — це запитання: де парабола вище (або нижче) осі x? Якщо ви розумієте, як виглядає парабола — відповідь читається прямо з графіка.

7. Що таке квадратна нерівність?

Квадратна нерівність — це нерівність вигляду ax² + bx + c > 0 (або ≥, <, ≤), де a ≠ 0.

На відміну від лінійної, тут x стоїть у квадраті, тому розв'язком може бути не один проміжок, а об'єднання двох проміжків або навіть порожня множина.

8. Алгоритм розв'язання квадратної нерівності

  1. Крок 1. Запишіть нерівність у стандартному вигляді: ax² + bx + c > 0
  2. Крок 2. Знайдіть дискримінант: D = b² − 4ac
  3. Крок 3. Знайдіть корені рівняння ax² + bx + c = 0 (якщо D ≥ 0): x₁,₂ = (−b ± √D) / 2a
  4. Крок 4. Визначте куди дивляться вітки: a > 0 — вгору, a < 0 — вниз.
  5. Крок 5. Визначте відповідь за схемою знаків (див. нижче).

Не потрібно будувати точний графік. Достатньо знати три речі: куди дивляться вітки (знак a), де корені (крок 3), і що шукаємо (де > 0 чи де < 0).

8.1 Схема знаків параболи (правило параболи)

Парабола — неперервна крива. Вона може змінити знак (перейти з «+» в «−» або навпаки) тільки там, де перетинає вісь x, тобто в коренях. Між коренями знак один, за коренями — інший. А коефіцієнт a визначає, який знак де:

Парабола y = ax² + bx + c перетинає вісь x у точках x₁ і x₂ (де x₁ < x₂) і поводить себе так:

a > 0
(вітки вгору)		ax² + bx + c > 0 при x < x₁ або x > x₂ (зовні коренів)
ax² + bx + c < 0 при x₁ < x < x₂ (між коренями)
a < 0
(вітки вниз)		ax² + bx + c > 0 при x₁ < x < x₂ (між коренями)
ax² + bx + c < 0 при x < x₁ або x > x₂ (зовні коренів)

Правило «Посміхайся або хмурся»

a > 0 — парабола «посміхається» ∪ (вітки вгору): більша за нуль по краях.

a < 0 — парабола «хмуриться» ∩ (вітки вниз): більша за нуль в середині.

8.2 Особливі випадки (дискримінант)

D > 0Два різні корені x₁ і x₂. Стандартна ситуація — застосовуємо правило параболи.
D = 0Один корінь (дотик): x₀ = −b / 2a.
Для a > 0: ax² + bx + c ≥ 0 для всіх x; ax² + bx + c > 0 для всіх x ≠ x₀.
Для a < 0: ax² + bx + c ≤ 0 для всіх x; ax² + bx + c < 0 для всіх x ≠ x₀.
D < 0Коренів немає — парабола не перетинає вісь x.
Для a > 0: ax² + bx + c > 0 для всіх x (завжди додатне).
Для a < 0: ax² + bx + c < 0 для всіх x (завжди від'ємне).

9. Приклади розв'язання квадратних нерівностей

9.1 Приклад 1: x² − 5x + 6 > 0

  1. Стандартний вигляд: вже є. a = 1 > 0 (вітки вгору).
  2. Дискримінант: D = 25 − 24 = 1 > 0
  3. Корені: x₁ = (5−1)/2 = 2; x₂ = (5+1)/2 = 3
  4. a > 0, нерівність > 0: відповідь зовні коренів

Чому зовні? a > 0 — парабола «усміхається» (U). Вона нижче осі між коренями 2 і 3, а вище осі — ліворуч від 2 і праворуч від 3. Нам потрібно > 0, тобто вище осі — це зовні коренів.

Відповідь: x ∈ (−∞; 2) ∪ (3; +∞)

9.2 Приклад 2: −x² + 4x − 3 ≥ 0

  1. Стандартний вигляд: −x² + 4x − 3 ≥ 0. a = −1 < 0 (вітки вниз).
  2. Дискримінант: D = 16 − 12 = 4 > 0
  3. Корені: x₁ = (−4+2)/(−2) = 1; x₂ = (−4−2)/(−2) = 3
  4. a < 0, нерівність ≥ 0: відповідь між коренями (включно)

Чому між? a < 0 — парабола «хмуриться» (∩). Вона вище осі тільки між коренями 1 і 3. ≥ 0 означає «вище або на осі» — тому корені включаємо (квадратні дужки [1; 3], а не круглі).

Відповідь: x ∈ [1; 3]

9.3 Приклад 3: x² + 2x + 5 < 0

  1. a = 1 > 0; D = 4 − 20 = −16 < 0.
  2. Коренів немає, парабола завжди вище осі x.

Відповідь: Розв'язків немає (∅).

Чому? D < 0 — парабола не торкається осі x взагалі. a > 0 — вона вся вище осі (завжди додатна). Нам потрібно < 0, тобто нижче осі — але парабола туди ніколи не заходить.

Короткий рецепт: знайдіть корені → подивіться на знак a →
a > 0 і потрібно > 0 — відповідь зовні коренів
a > 0 і потрібно < 0 — між коренями
a < 0 — навпаки
Строга нерівність (>, <) — круглі дужки. Нестрога (≥, ≤) — квадратні.
