ЧАСТИНА 1. ОСНОВНІ ПОНЯТТЯ

Теорія ймовірностей відповідає на питання «наскільки це ймовірно?». Прогноз погоди, оцінка ризиків, генетика, ігри — скрізь, де результат невизначений. На НМТ — класична ймовірність (m/n), формула Бернуллі та операції з подіями.

1. Випробування, події, простір

ВипробуванняДослід або експеримент, результат якого наперед невідомий.
Приклад: кидання монети, кубика, вибір карти
Простір елементарних подій ΩМножина всіх можливих результатів випробування.
Приклад: монета → Ω = {Г, Р}; кубик → Ω = {1,2,3,4,5,6}
Елементарна подія ωОдиничний результат. Не розкладається на простіші.
ω ∈ Ω
Подія AПідмножина Ω. Відбувається, коли результат належить A.
Приклад: «випало парне» = {2,4,6} ⊂ {1,2,3,4,5,6}
Достовірна подіяΩ — відбувається завжди. P(Ω) = 1
Неможлива подія∅ — не відбувається ніколи. P(∅) = 0

2. Класична ймовірність

Якщо всі елементарні події рівноможливі:

P(A) = m/n

де m — кількість сприятливих наслідків для A, n — загальна кількість наслідків

Приклад 1: Кубик. Ймовірність парного числа?

A = {2,4,6}, m=3, n=6
P(A) = 3/6 = 1/2

Приклад 2: 52 карти. Ймовірність туза?

m=4 (тузи), n=52
P(туз) = 4/52 = 1/13 ≈ 0,077

ЧАСТИНА 2. ОПЕРАЦІЇ НАД ПОДІЯМИ

3. Основні операції

Об'єднання A∪BПодія «A або B» відбувається, якщо відбудеться A, або B, або обидві.
P(A∪B) = P(A)+P(B)−P(A∩B)
Перетин A∩BПодія «A і B» — відбуваються обидві одночасно.
Доповнення ĀПодія «не A» — A не відбулась.
P(Ā) = 1 − P(A)
Корисно: часто простіше знайти P(Ā) і відняти від 1
Несумісні подіїA∩B = ∅ — не можуть відбутись одночасно.
P(A∪B) = P(A)+P(B) (формула спрощується)
Незалежні подіїРезультат A не впливає на результат B.
P(A∩B) = P(A)·P(B)

Формула включень-виключень (для трьох подій):

P(A∪B∪C) = P(A)+P(B)+P(C) − P(A∩B) − P(A∩C) − P(B∩C) + P(A∩B∩C)

ЧАСТИНА 3. УМОВНА ЙМОВІРНІСТЬ

4. Умовна ймовірність

Умовна ймовірність P(A|B) — ймовірність події A за умови, що B вже відбулась:

P(A|B) = P(A∩B) / P(B), P(B) > 0

Приклад: з 52 карт витягнули червону (26 карт). Яка ймовірність, що це туз?

A = {туз}, B = {червона}
P(A∩B) = 2/52 (червоні тузи), P(B) = 26/52
P(A|B) = (2/52)/(26/52) = 2/26 = 1/13

5. Формула повної ймовірності

Якщо B₁, B₂, …, Bₙ — повна група несумісних подій (гіпотез):

P(A) = Σ P(Bₖ)·P(A|Bₖ)

Приклад: два ящики. У 1-му: 3 білі, 7 чорних. У 2-му: 6 білих, 4 чорних. Вибирають ящик навмання, тягнуть кулю. P(біла)?

B₁={вибрали 1-й ящик}, B₂={вибрали 2-й}
P(B₁)=P(B₂)=0,5
P(біла|B₁)=3/10=0,3; P(біла|B₂)=6/10=0,6
P(біла) = 0,5·0,3 + 0,5·0,6 = 0,15+0,30 = 0,45

6. Формула Байєса

Дозволяє оновити ймовірність гіпотези після спостереження результату:

P(Bₖ|A) = P(Bₖ)·P(A|Bₖ) / P(A)

Продовження прикладу: куля виявилась білою. Яка ймовірність, що взяли 1-й ящик?

P(B₁|біла) = P(B₁)·P(біла|B₁) / P(біла)
= 0,5·0,3 / 0,45 = 0,15/0,45 = 1/3 ≈ 0,33

ЧАСТИНА 4. ДИСКРЕТНІ РОЗПОДІЛИ

7. Схема Бернуллі

n незалежних випробувань, у кожному — успіх з ймовірністю p, невдача — q=1−p. Ймовірність рівно k успіхів:

P(k) = Cₙᵏ · pᵏ · qⁿ⁻ᵏ

Приклад: монету кидають 5 разів. P(рівно 3 герби), p=0,5

P(3) = C₅³·(0,5)³·(0,5)² = 10·0,125·0,25 = 0,3125

Як обрати формулу

Що в задачіФормула
Скільки сприятливих з усіх рівноможливихP = m/n
«Або A, або B» (яка ймовірність хоча б одного)P(A∪B) = P(A)+P(B)−P(A∩B)
«І A, і B» (обидві одночасно, незалежні)P(A∩B) = P(A)·P(B)
«НЕ відбулось» або «хоча б одне»P(Ā) = 1−P(A). «Хоча б 1» = 1−P(жодного)
«Після того, як дізнались, що B відбулось»P(A|B) = P(A∩B)/P(B)
n однакових дослідів, k успіхівБернуллі: Cₙᵏ·pᵏ·qⁿ⁻ᵏ

Типові помилки

1. Забувають віднімати P(A∩B).
P(A∪B) = P(A)+P(B) працює тільки для несумісних подій! Для сумісних: P(A∪B) = P(A)+P(B)−P(A∩B). Без мінуса — подвійний рахунок.

2. Плутають несумісні і незалежні.
Несумісні: не можуть відбутись одночасно (A∩B = ∅) → P(A∪B) = P(A)+P(B). Незалежні: не впливають одна на одну → P(A∩B) = P(A)·P(B). Це різні поняття!

3. «Хоча б одне» рахують напряму.
P(хоча б 1 успіх з 5) — це НЕ 5·P(одного). Правильно: P = 1 − P(жодного) = 1 − q⁵. Набагато простіше через доповнення.

4. У формулі Бернуллі забувають Cₙᵏ.
P(3 герби з 5) = C₅³·(½)³·(½)² = 10·1/32, а не просто (½)³·(½)² = 1/32. Без C₅³ = 10 відповідь у 10 разів менша.
