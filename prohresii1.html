ЧАСТИНА 1. АРИФМЕТИЧНА ПРОГРЕСІЯ

Прогресії — це послідовності чисел, побудовані за простим правилом. Вони зустрічаються скрізь: нумерація поверхів, нарахування відсотків, рух з прискоренням. Якщо зрозуміти правило — можна знайти будь-який член послідовності або їх суму, не перераховуючи все підряд.

1. Що таке арифметична прогресія?

Арифметична прогресія (АП) — послідовність чисел, у якій кожний наступний член отримується з попереднього додаванням одного й того самого числа — різниці прогресії d.

Аналогія: Сходинки

Уявіть сходи, де кожна сходинка однакової висоти. Якщо перша сходинка на висоті a₁, а кожна наступна вища на d — це і є арифметична прогресія.

Загальний виглядa₁, a₂, a₃, …, aₙ, …
де a₂ = a₁ + d; a₃ = a₁ + 2d; …
Різниця d > 0Прогресія зростаюча (сходи вгору)
Приклад: 2, 5, 8, 11, 14, … (d = 3)
Різниця d < 0Прогресія спадаюча (сходи вниз)
Приклад: 10, 7, 4, 1, −2, … (d = −3)
Різниця d = 0Стала прогресія — всі члени рівні
Приклад: 5, 5, 5, 5, …

2. Формули арифметичної прогресії

2.1 Формула n-го члена

aₙ = a₁ + (n − 1) · d

Де: a₁ — перший член, d — різниця, n — номер члена.

Приклад: Знайти 10-й член прогресії 3, 7, 11, 15, …

a₁ = 3, d = 4, n = 10

a₁₀ = 3 + (10−1)·4 = 3 + 36 = 39

Перевірка: випишемо кілька членів: 3, 7, 11, 15, 19, 23, 27, 31, 35, 39 — десятий член справді 39 ✓

2.2 Властивість членів АП

aₙ = (aₙ₋₁ + aₙ₊₁) / 2

Кожний член АП (крім першого і останнього) є середнім арифметичним двох сусідніх членів.

Приклад: прогресія 2, 5, 8, 11, 14. Перевіримо для a₃ = 8: (a₂ + a₄)/2 = (5 + 11)/2 = 16/2 = 8 ✓. Це зручно для перевірки: якщо число не є середнім сусідів — десь помилка.

2.3 Сума перших n членів

Sₙ = (a₁ + aₙ) · n / 2

Або через a₁ та d:

Sₙ = (2a₁ + (n−1)·d) · n / 2

Аналогія: Гаус і сума чисел від 1 до 100

Маленький Гаус помітив: 1+100 = 101, 2+99 = 101, 3+98 = 101… Таких пар 50. Сума = 101·50 = 5050. Це і є формула суми АП!

Приклад: Знайти суму перших 20 членів прогресії 2, 5, 8, …

a₁ = 2, d = 3, n = 20

a₂₀ = 2 + 19·3 = 59

S₂₀ = (2 + 59)·20/2 = 61·10 = 610

3. Як знайти невідомі елементи АП

У формулі aₙ = a₁ + (n − 1)·d — чотири величини: a₁, d, n, aₙ. Якщо відомі будь-які три — четверту можна знайти:

Що відомоЩо знаходимоФормула
a₁, d, naₙaₙ = a₁ + (n − 1)·d
a₁, aₙ, ndd = (aₙ − a₁) / (n − 1)
aₙ, d, na₁a₁ = aₙ − (n − 1)·d
a₁, aₙ, dnn = (aₙ − a₁) / d + 1

Приклад 1: a₁ = 3, a₅ = 15. Знайти d і S₅.

a₅ = a₁ + 4d → 15 = 3 + 4d → d = 3

S₅ = (a₁ + a₅)·5/2 = (3 + 15)·5/2 = 18·5/2 = 45

Перевірка: 3, 6, 9, 12, 15. Сума: 3+6+9+12+15 = 45 ✓

Приклад 2: Скільки членів у прогресії 4, 7, 10, …, 61?

a₁ = 4, d = 3, aₙ = 61. n = (61 − 4)/3 + 1 = 57/3 + 1 = 19 + 1 = 20

Типові помилки

1. У формулі n-го члена пишуть n замість (n − 1).
Неправильно: a₁₀ = 3 + 10·4 = 43. Правильно: a₁₀ = 3 + (10−1)·4 = 39. Від першого до десятого члена — 9 кроків, а не 10.

2. Плутають d і aₙ.
Прогресія 5, 8, 11, 14. d = 3 (різниця між сусідніми), а не d = 14 (останній член). d знаходиться як a₂ − a₁.

3. Забувають, що d може бути від'ємним.
Прогресія 20, 17, 14, 11, … → d = −3, а не 3. Якщо послідовність спадає — d від'ємне.
