ЧАСТИНА 1. ЩО ТАКЕ ОБЕРНЕНА ФУНКЦІЯ

Пряма функція відповідає на питання «дано x — чому дорівнює y?». Обернена — навпаки: «дано y — яке було x?». Наприклад, sin дає значення за кутом, а arcsin — знаходить кут за значенням. Без обернених функцій неможливо розв'язувати тригонометричні рівняння.

1. Поняття оберненої функції

Обернена функція f⁻¹ — функція, яка «скасовує» дію f. Тобто f⁻¹(f(x)) = x і f(f⁻¹(y)) = y.

Умова існування:

Обернена функція існує, якщо вихідна функція є взаємно однозначною (бієктивною) — тобто кожному значенню y відповідає рівно одне x. Графічно: будь-яка горизонтальна пряма перетинає графік не більше одного разу.

Побудова графіка оберненої:

Графік оберненої функції — це відображення графіка вихідної відносно прямої y = x (дзеркало по діагоналі)

f(x) і f⁻¹(x)Область визначення f — область значень f⁻¹, і навпаки
f⁻¹(f(x)) = xНа ОДЗ f: обернена скасовує пряму
f(f⁻¹(y)) = yНа ОЗ f: пряма скасовує обернену

2. arcsin x

Визначенняarcsin x — кут α ∈ [−π/2; π/2], для якого sin α = x.
Обернена до sin x, обмеженого на [−π/2; π/2]
D(arcsin)[−1; 1]
E(arcsin)[−π/2; π/2]
Тотожностіsin(arcsin x) = x при x ∈ [−1; 1]
arcsin(sin x) = x при x ∈ [−π/2; π/2]
Парністьarcsin(−x) = −arcsin x (непарна функція)

Простою мовою: arcsin(½) = π/6, тому що sin(π/6) = ½. Тобто arcsin відповідає на питання «який кут має синус ½?» — і дає відповідь з проміжку [−π/2; π/2].

Приклад: arcsin(−√2/2) = −π/4, тому що sin(−π/4) = −√2/2 і −π/4 ∈ [−π/2; π/2].

3. arccos x

Визначенняarccos x — кут α ∈ [0; π], для якого cos α = x.
D(arccos)[−1; 1]
E(arccos)[0; π]
Тотожностіcos(arccos x) = x при x ∈ [−1; 1]
arccos(cos x) = x при x ∈ [0; π]
Співвідношенняarcsin x + arccos x = π/2
arccos(−x) = π − arccos x

Приклад: arccos(−½) = ? Знаємо arccos(½) = π/3. За формулою: arccos(−½) = π − π/3 = 2π/3. Перевірка: cos(2π/3) = −½ ✓

Типові помилки

1. Плутають область значень обернених функцій.
arcsin видає кут з [−π/2; π/2], arccos — з [0; π]. Тому arcsin(½) = π/6, а не 5π/6 (хоча sin(5π/6) теж = ½, але 5π/6 не входить у [−π/2; π/2]).

2. Пишуть arcsin(2) або arccos(−3).
arcsin і arccos визначені тільки для x ∈ [−1; 1]. Якщо аргумент виходить за межі — відповіді не існує.

3. Плутають arcsin(sin x) і sin(arcsin x).
sin(arcsin x) = x завжди (при x ∈ [−1;1]). Але arcsin(sin x) = x тільки при x ∈ [−π/2; π/2]! Наприклад: arcsin(sin 2π/3) = arcsin(√3/2) = π/3 ≠ 2π/3.

4. Забувають формулу arccos(−x) = π − arccos(x).
arccos(−½) ≠ −arccos(½). Правильно: arccos(−½) = π − π/3 = 2π/3. Мнемоніка: arcsin — непарна (мінус виноситься), arccos — ні (мінус замінюється на π−).
