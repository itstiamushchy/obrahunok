ЧАСТИНА 4. СТЕПЕНІ ТА КОРЕНІ

Степінь — це скорочений запис багаторазового множення. Корінь — зворотна операція: якщо степінь «будує», корінь «розбирає». Без них не обійтись: площа квадрата — це сторона у степені 2, об'єм куба — у степені 3, а знайти сторону за площею — це добути корінь.

10. Степені

Піднесення числа a до степеня n (позначення: aⁿ) означає множення числа a саме на себе n разів. Число a — основа, число n — показник степеня. Наприклад, 2⁵ = 2·2·2·2·2 = 32 — замість писати п'ять двійок, пишемо одну з показником.

aⁿ = a · a · a · … · a (n разів)

10.1 Від'ємна основа та парність показника

Парний показникВід'ємне число у парному степені дає додатний результат.
Приклад: (−3)² = (−3)·(−3) = 9
Непарний показникВід'ємне число у непарному степені залишається від'ємним.
Приклад: (−2)³ = (−2)·(−2)·(−2) = −8

⚠ Типова помилка

(−3)² = 9, але −3² = −9. Це різні речі! Без дужок мінус не підноситься до степеня: −3² означає «взяти 3², і поставити мінус», тобто −(3²) = −9.

10.2 Основні властивості степенів

Для a > 0, b > 0 і довільних показників m, n:

ВластивістьФормулаПриклад
Множення (однакові основи)aᵐ · aⁿ = aᵐ⁺ⁿ2³ · 2⁴ = 2⁷ = 128
Ділення (однакові основи)aᵐ : aⁿ = aᵐ⁻ⁿ (a≠0)5⁶ : 5⁴ = 5² = 25
Степінь степеня(aᵐ)ⁿ = aᵐ·ⁿ(3²)³ = 3⁶ = 729
Степінь добутку(a·b)ⁿ = aⁿ·bⁿ(2·5)³ = 8·125 = 1000
Степінь частки(a/b)ⁿ = aⁿ/bⁿ (b≠0)(3/2)² = 9/4
Нульовий показникa⁰ = 1 (a≠0)7⁰ = 1
Від'ємний показникa⁻ⁿ = 1/aⁿ (a/b)⁻ⁿ = (b/a)ⁿ2⁻³ = 1/8 = 0,125

Чому a⁰ = 1?

За правилом ділення: aⁿ/aⁿ = aⁿ⁻ⁿ = a⁰. Але будь-яке число, поділене на себе = 1.
Можна зрозуміти інакше: 2³ = 8, 2² = 4, 2¹ = 2 — кожен раз ділимо на 2. Наступний крок: 2⁰ = 2 : 2 = 1. Закономірність працює.
Зауваження: 0⁰ у шкільній математиці не має змісту.

11. Корені

Добування кореня — операція, обернена до піднесення до степеня.

11.1 Квадратний корінь

Арифметичний квадратний корінь із числа a (позначення: √a) — це невід'ємне число b, квадрат якого дорівнює a:

Чому тільки невід'ємне? Квадрат 49 мають два числа: 7 і −7. Але домовились: символ √ завжди повертає додатне значення. Якщо потрібні обидва відповіді — пишемо ±√49 = ±7.

√a = b ⟺ b² = a, де a ≥ 0, b ≥ 0

Важливо: підкореневе значення для парного кореня не може бути від'ємним (√(−16) у ℝ не має змісту).
Приклад: √49 = 7, бо 7 ≥ 0 і 7² = 49. (−7)² теж = 49, але арифметичний корінь завжди ≥ 0)

11.2 Корінь n-го степеня

Вираз ⁿ√a шукає таке число, n-ий степінь якого = a.

n — парне (2,4,6…)a ≥ 0, результат ≥ 0. Приклад: ⁴√16 = 2
n — непарне (3,5,7…)Корінь можна добувати з будь-якого числа, включно з від'ємними.
Приклад: ³√(−27) = −3, бо (−3)³ = −27

11.3 Основні властивості коренів

Для a ≥ 0, b > 0:

Корінь з добуткуⁿ√(a·b) = ⁿ√a · ⁿ√b
Приклад: √(36·25) = √36 · √25 = 6·5 = 30
Корінь з часткиⁿ√(a/b) = ⁿ√a / ⁿ√b
Приклад: √(9/16) = √9/√16 = 3/4
Степінь кореня(ⁿ√a)ᵐ = ⁿ√(aᵐ)
Тотожність (модульна)√(a²) = |a|
Гарантує невід'ємний результат: √((−5)²) = |−5| = 5
Квадрат кореня(√a)² = a (при a ≥ 0)
Винесення з-під кореня√50 = √(25·2) = 5√2

11.4 Степінь з дробовим показником

Тепер степені та корені стають однією системою. Будь-який корінь — це просто степінь з дробом у показнику:

Будь-який корінь можна записати як степінь з дробовим показником:

ⁿ√(aᵐ) = a^(m/n) (a > 0)

  • Чисельник m — степінь, до якого підноситься число.
  • Знаменник n — показник кореня, який добувається.

Приклад 1: √a = a^(1/2)
Приклад 2: ³√(8²) = 8^(2/3) = (³√8)² = 2² = 4

Навіщо це зручно?

Дробові показники дозволяють застосовувати всі 7 властивостей степенів до виразів з коренями, не вивчаючи окремих складних правил.
