ПІДСУМОК — ПАМ'ЯТКА

Ця пам'ятка — для швидкого повторення. Якщо щось незрозуміло — поверніться до відповідної частини.

Порівняння чисел

Різниця a − bЯкщо > 0 → a > b. Якщо < 0 → a < b. Якщо = 0 → a = b.
ДробиХрест-навхрест: a/b і c/d → порівнюємо a·d і b·c (зводимо до спільного знаменника без запису)
КореніПідносимо до квадрата: √a і √b → порівнюємо a і b. Тільки для додатних!
Степені, однакова основаПорівнюємо показники. Але тільки якщо основа > 1! Для основи між 0 і 1 — навпаки
Степені, однаковий показникПорівнюємо основи. Обережно з від'ємними основами при непарному показнику

Лінійна нерівність: ax + b > 0

  1. Перенести x вліво, числа вправо
  2. Спростити (звести подібні)
  3. Поділити на коефіцієнт при x. Якщо він від'ємний — змінити знак!
  4. Записати відповідь як проміжок
  5. Перевірити підстановкою

Квадратна нерівність: ax² + bx + c > 0

  1. Привести до стандартного вигляду
  2. Знайти D = b² − 4ac → корені
  3. Визначити знак a → тип параболи
  4. Правило параболи:
потрібно > 0потрібно < 0
a > 0 (U)зовні коренівміж коренями
a < 0 (∩)між коренямизовні коренів

D = 0 — один корінь (парабола торкається осі). D < 0 — коренів немає (все додатне якщо a > 0, все від'ємне якщо a < 0).

Проміжки

( ) кругліТочка НЕ входить. Строга нерівність (>, <)
[ ] квадратніТочка ВХОДИТЬ. Нестрога нерівність (≥, ≤)
∞Завжди з круглою дужкою — нескінченність не число

Типові помилки

1. Забули змінити знак при діленні на від'ємне. −2x > 6 → x < −3, а не x > −3!

2. (x + 3)² > 0 — не означає «завжди правда», бо при x = −3 буде = 0, а нам потрібно строго > 0.

3. Плутають «зовні» і «між»: a > 0 і потрібно > 0 — зовні коренів (парабола вгору, вище осі по краях). Якщо не впевнені — підставте число з кожної ділянки і перевірте.
