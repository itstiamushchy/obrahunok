ЧАСТИНА 4. ПІДСУМОК — ПАМ'ЯТКА

Ця пам'ятка — для швидкого повторення перед НМТ. Усі формули АП і ГП в одному місці. Якщо щось незрозуміло — поверніться до частин 6.1–6.3.

Усі формули АП

Що шукаємоФормулаПриклад
n-й членaₙ = a₁ + (n − 1)·da₁=3, d=4, n=10 → a₁₀ = 3+9·4 = 39
Різницяd = (aₙ − a₁) / (n − 1)a₁=2, a₆=17 → d = 15/5 = 3
Перший членa₁ = aₙ − (n − 1)·da₅=19, d=4 → a₁ = 19−4·4 = 3
Кількість членівn = (aₙ − a₁) / d + 1a₁=4, aₙ=61, d=3 → n = 57/3+1 = 20
Сума (через крайні)Sₙ = (a₁ + aₙ) · n / 2a₁=2, a₂₀=59, n=20 → S₂₀ = 610
Сума (через a₁ і d)Sₙ = (2a₁ + (n−1)·d) · n / 2a₁=2, d=3, n=20 → S₂₀ = 610
Перевіркаaₙ = (aₙ₋₁ + aₙ₊₁) / 25, 8, 11: 8 = (5+11)/2 ✓

Усі формули ГП

Що шукаємоФормулаПриклад
n-й членbₙ = b₁ · qⁿ⁻¹b₁=3, q=2, n=6 → b₆ = 3·32 = 96
Знаменникq = bₙ₊₁ / bₙ (або ⁿ⁻¹√(bₙ/b₁))b₁=2, b₄=16 → q = ³√8 = 2
Перший членb₁ = bₙ / qⁿ⁻¹b₅=48, q=2 → b₁ = 48/16 = 3
Сума n членівSₙ = b₁ · (qⁿ − 1) / (q − 1)b₁=2, q=3, n=5 → S₅ = 242
Нескінченна сумаS∞ = b₁ / (1 − q), тільки |q| < 1!b₁=1, q=½ → S∞ = 2
Перевіркаbₙ² = bₙ₋₁ · bₙ₊₁2, 6, 18: 6² = 2·18 = 36 ✓

Практичні задачі

Задача 1 (АП): Кількість місць у залі

У кінозалі перший ряд має 20 місць, кожен наступний — на 2 місця більше. Скільки місць у залі з 15 рядами?

АП: a₁ = 20, d = 2, n = 15

a₁₅ = 20 + 14·2 = 48

S₁₅ = (20 + 48)·15/2 = 68·15/2 = 510 місць

Перевірка: середнє на ряд = 510/15 = 34 = (20+48)/2 ✓

Задача 2 (ГП): Бактерії

Кількість бактерій подвоюється щогодини. Спочатку їх 100. Скільки буде через 8 годин?

ГП: b₁ = 100, q = 2, n = 9 (через 8 годин — дев'ятий член)

b₉ = 100 · 2⁸ = 100 · 256 = 25 600 бактерій

Задача 3 (S∞): Періодичний десятковий дріб

Довести, що 0,(3) = 0.333… = 1/3

0.333… = 3/10 + 3/100 + 3/1000 + … — нескінченна ГП

b₁ = 3/10, q = 1/10 (|q| < 1 ✓)

S∞ = (3/10) / (1 − 1/10) = (3/10) / (9/10) = 3/9 = 1/3 ✓

Вставлення середніх членів

ЗадачаФормулаПриклад
Вставити k середніх в АП між a і bd = (b − a) / (k + 1)Між 2 і 14 вставити 3 середніх: d = 12/4 = 3 → 2, 5, 8, 11, 14
Вставити 1 середній в ГП між a і bСередній = √(a · b)Між 4 і 16: √(4·16) = √64 = 8 → 4, 8, 16

Чеклист перед відповіддю (НМТ)

☐ Визначив тип: АП (додавання) чи ГП (множення)?
☐ Правильно записав a₁ (або b₁) — саме перший член, не нульовий?
☐ У показнику степеня (n − 1), а не n?
☐ Якщо задача про відсотки: q = 1 + р/100 (не плутати з р)?
☐ Якщо задача «через k років» — кількість членів = k + 1?
☐ Перевірив відповідь: підставив у формулу або порахував кілька членів вручну?

Типові помилки — зведення

1. (n − 1) замість n. Від першого до десятого — 9 кроків. aₙ = a₁ + (n−1)·d, bₙ = b₁·qⁿ⁻¹.

2. Відсотки — це множення. «На 10% більше» = ×1.1. «На 20% менше» = ×0.8. Не додавання!

3. Кількість членів vs кількість кроків. «Через 3 роки» при щорічному нарахуванні — це b₄ (4-й член), не b₃.

4. S∞ тільки при |q| < 1. Якщо |q| ≥ 1 — нескінченна сума не існує. Формула дасть неправильний результат.

5. Від'ємні d або q. d < 0 — АП спадає. q < 0 — знаки чергуються. Це нормально, не помилка.

Прогресії — одна з найпростіших тем НМТ: всього кілька формул, і всі задачі зводяться до підстановки. Головне — не плутати (n−1) з n.
