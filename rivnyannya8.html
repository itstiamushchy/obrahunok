Ця пам'ятка — для швидкого повторення перед контрольною або НМТ. Якщо щось незрозуміло — поверніться до відповідної частини (4.1–4.7).

Лінійне рівняння: ax + b = 0

  1. Розкрити дужки (якщо є)
  2. Перенести всі доданки з x вліво, числа — вправо (при переносі змінюємо знак)
  3. Звести подібні доданки
  4. Поділити обидві частини на коефіцієнт при x

Особливі випадки: якщо коефіцієнт при x дорівнює 0, то рівняння або не має розв'язків (0·x = 5 — хибність), або має нескінченно багато (0·x = 0 — тотожність).

Квадратне рівняння: ax² + bx + c = 0

  1. Записати коефіцієнти a, b, c
  2. Обчислити дискримінант: D = b² − 4ac
  3. За знаком D визначити кількість коренів:
D > 0Два корені: x = (−b ± √D) / 2a
D = 0Один корінь: x = −b / 2a
D < 0Розв'язків немає

Перевірка формулами Вієта: x₁ + x₂ = −b/a, x₁ · x₂ = c/a. Якщо не сходиться — шукай помилку в обчисленнях.

Неповні квадратні: ax² + bx = 0 → виносимо x. ax² + c = 0 → виражаємо x².

Раціональне рівняння (з дробами, де x у знаменнику)

  1. ОДЗ (область допустимих значень) — знаменник ≠ 0. Записати, при яких x знаменник обертається в нуль
  2. Помножити обидві частини на спільний знаменник — дроби зникають
  3. Розв'язати отримане рівняння (зазвичай лінійне або квадратне)
  4. Перевірка: підставити кожний корінь в ОДЗ. Якщо корінь робить знаменник нулем — він сторонній, відкидаємо

Ірраціональне рівняння (з коренями)

  1. Ізолювати корінь: перенести все інше на другий бік
  2. Піднести обидві частини до квадрата (якщо √) — корінь зникає
  3. Розв'язати отримане рівняння
  4. Перевірка підстановкою обов'язкова! Піднесення до квадрата може дати сторонні корені

Умова: підкореневий вираз ≥ 0, а якщо корінь стоїть рівним чомусь, то та частина теж ≥ 0.

Показникове рівняння (x у показнику)

  1. Спробувати звести обидві частини до однакової основи: 8 = 2³, 27 = 3³, 1/4 = 2⁻²
  2. Якщо основи однакові → прирівняти показники
  3. Якщо не вдається — заміна: нехай t = aˣ, тоді a²ˣ = t², aˣ⁺¹ = a·t
  4. Розв'язати рівняння відносно t, потім повернутися: aˣ = t

Пам'ятай: aˣ завжди > 0, тому від'ємні та нульові значення t відкидаємо.

Логарифмічне рівняння

  1. ОДЗ: аргумент логарифма > 0 (і основа > 0, ≠ 1)
  2. Спростити, використовуючи властивості логарифмів (сума → логарифм добутку тощо)
  3. Потенціювання: якщо log_a(f(x)) = b, то f(x) = aᵇ
  4. Перевірка в ОДЗ — чи аргументи залишаються додатними при знайдених x

Тригонометричне рівняння

sin x = ax = (−1)ⁿ · arcsin a + πn, n ∈ ℤ
cos x = ax = ± arccos a + 2πn, n ∈ ℤ
tg x = ax = arctg a + πn, n ∈ ℤ
ctg x = ax = arcctg a + πn, n ∈ ℤ

Порядок дій: спростити рівняння (формули подвійного кута, зведення тощо) → звести до одного з табличних → записати загальну формулу → n ∈ ℤ означає нескінченну кількість коренів.

Для відбору коренів на проміжку — підставити n = 0, ±1, ±2… поки корені потрапляють у потрібний інтервал.

Порядок: розв'язати систему → знайти обидві змінні → підставити в обидва рівняння для перевірки.

Для нелінійних систем — зазвичай підстановка: з простішого рівняння виразити одну змінну, підставити в складніше.

Типові помилки

1. Забули ОДЗ у раціональному рівнянні.
Приклад: (x² − 4)/(x − 2) = 0. Розв'язуємо x² − 4 = 0 → x = ±2. Але x = 2 робить знаменник нулем → відкидаємо. Відповідь: x = −2.

2. Не перевірили ірраціональне рівняння.
Приклад: √(x + 3) = x − 1. Підносимо до квадрата → x + 3 = x² − 2x + 1 → x² − 3x − 2 = 0. Отримуємо два корені, але один із них робить праву частину від'ємною — він сторонній.

3. Загубили корінь у квадратному рівнянні.
Скоротили обидві частини на x: x² = 5x → x = 5. Але загубили x = 0! Правильно: x² − 5x = 0 → x(x − 5) = 0 → x = 0 або x = 5.

4. Показникове: прийняли від'ємний t.
Заміна t = 2ˣ дає t² − 3t − 4 = 0 → t = 4 або t = −1. Але 2ˣ не може бути від'ємним → t = −1 відкидаємо.

5. Тригонометричне: забули + πn або + 2πn.
sin x = ½ → x = π/6. Це лише один корінь. Повна відповідь: x = (−1)ⁿ · π/6 + πn, n ∈ ℤ.

6. Система: підставили тільки в одне рівняння.
Корінь має задовольняти обидва рівняння одночасно. Підставляй в обидва — інакше можеш прийняти сторонній розв'язок.

Головне правило для всіх рівнянь — перевіряй відповідь підстановкою в початкове рівняння.
