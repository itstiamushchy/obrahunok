ЧАСТИНА 1. ГРАНИЦІ

Границя — це відповідь на питання «до чого наближається функція?». Без границь неможливо визначити похідну, а без похідної — досліджувати функції на зростання, спадання, екстремуми. Це фундамент математичного аналізу.

1. Поняття границі

Границя функції в точці a — це значення, до якого наближається f(x) при x → a (але x ≠ a):

lim f(x) = L при x→a

Це не обов'язково значення f(a) — функція може навіть бути не визначена в точці a

Аналогія: Дорога до міста

Границя — це куди ви їдете (ціль), а не те, де зупинились. Можна наближатись до міста нескінченно, але не доїхати — границя все одно є.

Однобічні границіЛіва: lim f(x) при x→a⁻ (наближаємось зліва)
Права: lim f(x) при x→a⁺ (наближаємось справа)
Границя існує ⟺ ліва = права
Границя = ∞Якщо f(x) необмежено зростає: lim f(x) = +∞
Або: lim f(x) = −∞ (необмежено спадає)
Границя на нескінченностіlim f(x) при x→∞ — поведінка при великих x

2. Властивості границь

Сума/різницяlim(f±g) = lim f ± lim g
Добутокlim(f·g) = lim f · lim g
Часткаlim(f/g) = lim f / lim g (якщо lim g ≠ 0)
Константаlim c = c та lim(c·f) = c·lim f
Неперервна функціяlim f(g(x)) = f(lim g(x)) (якщо f неперервна)

3. Перший та другий чудові границі

Перша чудова границя:

lim (sin x)/x = 1 при x→0

Друга чудова границя:

lim (1 + 1/n)ⁿ = e ≈ 2,71828… при n→∞

Або: lim (1+x)^(1/x) = e при x→0

4. Розкриття невизначеностей

0/0Розкласти чисельник і знаменник на множники, скоротити.
Приклад: lim(x²−4)/(x−2) = lim(x+2)(x−2)/(x−2) = lim(x+2) = 4
∞/∞Поділити числ. і знам. на старший степінь.
Приклад: lim(3x²+1)/(x²−5) = lim(3+1/x²)/(1−5/x²) = 3/1 = 3
∞−∞Множити на спряжений вираз або виносити спільний множник.
1^∞, 0⁰, ∞⁰Зводити до e через формулу: lim f(x)^g(x) = e^(lim g(x)·ln f(x))

ЧАСТИНА 2. ПОХІДНА

5. Визначення похідної

Похідна f'(x) — миттєва швидкість зміни функції в точці x:

f'(x) = lim [f(x+Δx)−f(x)] / Δx при Δx→0

← зменшуй Δx, щоб побачити, як січна стає дотичною

Геометричний зміст: кутовий коефіцієнт дотичної до графіка f(x) в точці x

Фізичний зміст: миттєва швидкість (якщо f(t) — шлях, то f'(t) — швидкість)

7. Правила диференціювання

Константа(c·f)' = c·f'
Сума/різниця(f±g)' = f'±g'
Добуток(f·g)' = f'·g + f·g'
Частка(f/g)' = (f'·g − f·g') / g²
Складена функція
(правило ланцюжка)		(f(g(x)))' = f'(g(x))·g'(x)
Приклад: (sin(x²))' = cos(x²)·2x

ЧАСТИНА 3. ЗАСТОСУВАННЯ ПОХІДНОЇ

8. Дотична до графіка

y − y₀ = f'(x₀)·(x − x₀)

де (x₀; y₀) — точка на графіку, f'(x₀) — кутовий коефіцієнт дотичної

9. Монотонність та екстремуми

f'(x) > 0 на (a;b)f — зростає на (a;b)
f'(x) < 0 на (a;b)f — спадає на (a;b)
f'(x₀) = 0Точка x₀ — підозріла на екстремум (критична точка)
Максимумf'(x₀)=0 і f' змінює знак з + на − при проходженні x₀
Мінімумf'(x₀)=0 і f' змінює знак з − на + при проходженні x₀

10. Друга похідна — опуклість та точки перегину

f''(x) > 0 на (a;b)f — опукла донизу (посміхається ∪) на (a;b)
f''(x) < 0 на (a;b)f — опукла догори (хмуриться ∩) на (a;b)
f''(x₀) = 0Підозріла на точку перегину (де змінюється напрямок опуклості)
Максимум через f''Якщо f'(x₀)=0 і f''(x₀)<0 — максимум
Мінімум через f''Якщо f'(x₀)=0 і f''(x₀)>0 — мінімум

11. Правило Лопіталя

При невизначеностях 0/0 або ∞/∞ можна диференціювати числівник і знаменник окремо:

lim f(x)/g(x) = lim f'(x)/g'(x) (якщо права частина існує)

Приклад: lim(sinx)/x при x→0

Невизначеність 0/0. Правило Лопіталя:
lim(sinx)/x = lim(cosx)/1 = cos0 = 1

Алгоритм дослідження функції

1. Знайти D(f)
2. Парність/непарність
3. Знайти f'(x)
4. Критичні точки: f'(x) = 0
5. Знак f' на проміжках → зростання/спадання
6. Зміна знака f' → max/min
7. f''(x) → опуклість, точки перегину
8. Поведінка при x → ±∞, асимптоти
9. Побудувати графік

Типові помилки

1. Плутають (f·g)' і f'·g'.
(f·g)' = f'·g + f·g' (правило добутку). Це НЕ f'·g'. Наприклад: (x²·sinx)' = 2x·sinx + x²·cosx, а не 2x·cosx.

2. Забувають мінус у (cosx)' = −sinx.
(sinx)' = cosx (без мінуса). (cosx)' = −sinx (з мінусом!). Одна з найчастіших помилок.

3. f'(x₀) = 0 ще не означає екстремум.
f(x) = x³: f'(0) = 0, але це не екстремум (точка перегину). Потрібно перевірити зміну знака f' або використати f''.

4. Забувають внутрішню похідну (ланцюжкове правило).
(sin(3x))' = cos(3x)·3, а не просто cos(3x). (e^(x²))' = e^(x²)·2x. Множити на похідну внутрішньої функції!
