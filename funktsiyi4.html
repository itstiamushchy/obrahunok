ЧАСТИНА 4. ОСНОВНІ ФУНКЦІЇ ТА ЇХ ГРАФІКИ (2/2)

Продовжуємо каталог функцій. У цій частині — гіпербола, показникова, логарифмічна та тригонометричні функції. Кожна записана у повній параметричній формі з усіма коефіцієнтами, які впливають на графік.

12. Гіпербола: y = k/(x − p) + q

Найпростіший варіант y = k/x — це окремий випадок (p = 0, q = 0). Повна форма містить три параметри:

ПараметрЩо робитьЯк бачити на графіку
kРозтяг і напрям гілокk > 0: гілки в I та III чвертях (відносно центру)
k < 0: гілки в II та IV чвертях
|k| більше → гілки далі від центру
pЗсув центру по горизонталіВертикальна асимптота зсувається: x = p
qЗсув центру по вертикаліГоризонтальна асимптота зсувається: y = q
D(f)x ≠ p, тобто (−∞; p) ∪ (p; +∞)
E(f)y ≠ q, тобто (−∞; q) ∪ (q; +∞)
АсимптотиВертикальна: x = p. Горизонтальна: y = q
ПарністьНепарна лише при p = 0 та q = 0

13. Показникова функція: y = a·bˣ + c

Найпростіший варіант y = bˣ — це окремий випадок (a = 1, c = 0). Повна форма:

ПараметрЩо робитьЯк бачити на графіку
b — основа (b > 0, b ≠ 1)Визначає швидкість зростання або спаданняb > 1: зростає (чим більше b, тим крутіше)
0 < b < 1: спадає
a — множникРозтяг по вертикалі та відображенняa > 0: графік над асимптотою
a < 0: графік під асимптотою (відображення)
c — зсувЗсув по вертикаліГоризонтальна асимптота: y = c
D(f)ℝ
E(f)(c; +∞) при a > 0;   (−∞; c) при a < 0
Завжди проходить через(0; a + c) — підставте x = 0: y = a·b⁰ + c = a + c
Головнеbˣ завжди > 0, тому графік ніколи не торкається асимптоти y = c

14. Логарифмічна функція: y = a·logb(x − p) + q

Найпростіший варіант y = logbx — це окремий випадок (a = 1, p = 0, q = 0). Повна форма:

ПараметрЩо робитьЯк бачити на графіку
b — основа (b > 0, b ≠ 1)Визначає напрямb > 1: зростає   0 < b < 1: спадає
aРозтяг по вертикалі|a| > 1: крутіше, |a| < 1: пологіше
a < 0: відображення відносно OX
pЗсув по горизонталіВертикальна асимптота: x = p
qЗсув по вертикаліВесь графік зсувається на q вгору/вниз
D(f)x > p, тобто (p; +∞)
E(f)ℝ
АсимптотаВертикальна: x = p
Завжди проходить через(p + 1; q) — бо logb(1) = 0
Зв'язок з показниковоюy = logbx і y = bˣ — обернені функції (графіки симетричні відносно y = x)

15. Тригонометричні функції: y = A·sin(ωx + φ) + d

Базові y = sin x та y = cos x — це окремі випадки (A = 1, ω = 1, φ = 0, d = 0). Повна форма має чотири параметри, кожен відповідає за свою характеристику хвилі:

ПараметрНазваЩо робитьЯк бачити на графіку
AАмплітудаВисота хвиліГрафік коливається від d − |A| до d + |A|
A < 0: хвиля перевернута
ω (омега)Кутова частотаВизначає період: T = 2π/|ω|ω більше → хвиля стиснута (частіші коливання)
ω менше → хвиля розтягнута
φ (фі)Фаза (зсув)Зсув хвилі по горизонталіφ > 0: хвиля зсувається вліво
φ < 0: вправо
dВертикальний зсувЗсув середньої лініїВся хвиля піднімається (d > 0) або опускається (d < 0)
D(f)ℝ
E(f)[d − |A|; d + |A|]
ПеріодT = 2π / |ω|
Парність sinНепарна (при φ = 0, d = 0)
Парність cosПарна (при φ = 0, d = 0)

Типові помилки

1. Гіпербола y = k/x записують без параметрів p, q.
y = 3/(x − 2) + 1 — це гіпербола з центром у точці (2; 1), а не у початку координат. Асимптоти: x = 2 і y = 1, а не x = 0 і y = 0.

2. Показникова: забувають, що bˣ > 0 завжди.
Рівняння 2ˣ = −3 не має розв'язків. Графік y = 2ˣ ніколи не опускається нижче нуля (або нижче c, якщо є зсув).

3. Логарифм: плутають умову для основи і аргументу.
Основа b: > 0 та ≠ 1. Аргумент (x − p): строго > 0. Це різні вимоги!

4. Тригонометрія: плутають період з частотою.
y = sin(2x) — частота ω = 2, тому період T = 2π/2 = π (не 2π!). Хвиля стиснута вдвічі, коливається вдвічі частіше.

5. Тригонометрія: зсув фази у протилежний бік.
y = sin(x + π/3) — графік зсунутий вліво на π/3, а не вправо. Знак всередині дужок — протилежний до напрямку зсуву (як і для y = f(x + c)).
