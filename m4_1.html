ЧАСТИНА 1. НЕВИЗНАЧЕНИЙ ІНТЕГРАЛ

Інтеграл — обернена операція до похідної. Якщо похідна відповідає на «яка швидкість?», то інтеграл — «який шлях?». Невизначений інтеграл знаходить первісну (формулу), визначений — обчислює площу під графіком.

1. Первісна і невизначений інтеграл

Первісна F(x) — функція, похідна якої дорівнює f(x): F'(x) = f(x).

Невизначений інтеграл — множина всіх первісних:

∫ f(x) dx = F(x) + C

де C — довільна константа (оскільки C' = 0, будь-яка константа «пропадає» при диференціюванні)

Аналогія: Інтеграл — зворотна операція до похідної

Якщо похідна — це «газ» (швидкість зміни), то інтеграл — «шлях» (накопичена зміна). Знаючи швидкість → відновлюємо положення.

ЧАСТИНА 2. МЕТОДИ ІНТЕГРУВАННЯ

4. Метод підстановки (заміни змінної)

Якщо інтеграл містить складену функцію — замінюємо внутрішню функцію на нову змінну:

Алгоритм:

1. Виявити внутрішню функцію u = g(x)
2. Знайти du = g'(x)dx
3. Виразити весь інтеграл через u і du
4. Взяти інтеграл від простої функції
5. Повернутись до x: підставити u = g(x)

Приклад: ∫ sin(2x) dx

u = 2x, du = 2dx, dx = du/2
∫ sin(u)·du/2 = −cos(u)/2 + C = −cos(2x)/2 + C

Приклад 2: ∫ x·e^(x²) dx

u = x², du = 2x dx, x dx = du/2
∫ eᵘ·du/2 = eᵘ/2 + C = e^(x²)/2 + C

5. Інтегрування частинами

Для інтегралів виду ∫ u·dv (добуток двох функцій різного типу):

∫ u·dv = u·v − ∫ v·du

Правило вибору u (LIATE):

L — Логарифм (ln x, log x)
I — Обернені тригонометричні (arcsin, arctg…)
A — Алгебраїчна (xⁿ)
T — Тригонометрична (sin x, cos x)
E — Експоненціальна (eˣ, aˣ)

U вибирається першим із цього списку

Приклад: ∫ x·eˣ dx

u = x, dv = eˣdx
du = dx, v = eˣ
∫ x·eˣ dx = x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = eˣ(x−1) + C

Приклад 2: ∫ ln x dx

u = ln x, dv = dx
du = dx/x, v = x
∫ ln x dx = x·ln x − ∫ x·(1/x)dx = x·ln x − ∫ 1 dx = x·ln x − x + C

6. Часткові дроби (розкладання раціональних функцій)

Якщо знаменник розкладається на множники — розбиваємо на суму простих дробів:

Приклад: ∫ 1/(x²−1) dx = ∫ 1/((x−1)(x+1)) dx

1/((x−1)(x+1)) = A/(x−1) + B/(x+1)
1 = A(x+1) + B(x−1)
При x=1: 1=2A → A=½
При x=−1: 1=−2B → B=−½
∫ dx/(x²−1) = ½·ln|x−1| − ½·ln|x+1| + C = ½·ln|(x−1)/(x+1)| + C

ЧАСТИНА 3. ВИЗНАЧЕНИЙ ІНТЕГРАЛ

7. Визначений інтеграл і формула Ньютона-Лейбніца

Визначений інтеграл від a до b — площа між графіком f(x), віссю OX і вертикалями x=a, x=b:

∫[a;b] f(x) dx = F(b) − F(a)

n = 5 прямокутників

де F(x) — будь-яка первісна f(x). Це формула Ньютона-Лейбніца

Приклад: ∫[0;1] x² dx

F(x) = x³/3
∫[0;1] x² dx = F(1)−F(0) = 1/3 − 0 = 1/3

8. Властивості визначеного інтеграла

Адитивність∫[a;b]f dx = ∫[a;c]f dx + ∫[c;b]f dx (c між a і b)
Межі навпаки∫[b;a]f dx = −∫[a;b]f dx
Нульові межі∫[a;a]f dx = 0
Оцінка інтегралаЯкщо m ≤ f(x) ≤ M на [a;b], то: m(b−a) ≤ ∫[a;b]f dx ≤ M(b−a)
Непарна функція∫[−a;a] f(x) dx = 0 (якщо f — непарна)
Парна функція∫[−a;a] f(x) dx = 2·∫[0;a] f(x) dx (якщо f — парна)

ЧАСТИНА 4. ЗАСТОСУВАННЯ ІНТЕГРАЛА

9. Площа фігур

Між кривою і OXЯкщо f(x) ≥ 0 — модуль не потрібен
Між двома кривимиде f(x) — верхня крива, g(x) — нижня

Приклад: площа між y=x² і y=x

Перетин: x²=x → x=0 і x=1
S = ∫[0;1] (x−x²)dx = [x²/2 − x³/3]₀¹ = 1/2−1/3 = 1/6

10. Об'єм тіла обертання

V = π·∫[a;b] [f(x)]² dx (обертання навколо OX)

Приклад: V тіла, утвореного обертанням y=√x навколо OX, x∈[0;4]

V = π·∫[0;4] (√x)² dx = π·∫[0;4] x dx = π·[x²/2]₀⁴ = π·8 = 8π

11. Невласні інтеграли

Нескінченна межаЗбігається або розбігається
Приклад збіжного∫[1;∞] 1/x² dx = lim[−1/x]₁ᵇ = 0−(−1) = 1
Приклад розбіжного∫[1;∞] 1/x dx = lim[ln x]₁ᵇ = ∞ — розбігається

Типові помилки

1. Забувають + C у невизначеному інтегралі.
∫x²dx = x³/3 + C. Без C — це лише одна первісна з нескінченної множини. У визначеному інтегралі C не потрібна (вона скорочується).

2. Знак мінус при ∫sinx dx.
∫sinx dx = −cosx + C (мінус!). ∫cosx dx = sinx + C (без мінуса). Перевірка: (−cosx)' = sinx ✓

3. Забувають поділити при підстановці.
∫cos(3x)dx. u=3x, du=3dx, dx=du/3. Результат: sin(3x)/3+C, а не sin(3x)+C.

4. У площі між кривими забувають модуль або порядок.
S = ∫|f(x)−g(x)|dx. Якщо f < g на частині проміжку — потрібно розбити інтеграл і окремо рахувати кожну ділянку, або брати |верхня − нижня|.
