ЧАСТИНА 2. ГЕОМЕТРИЧНА ПРОГРЕСІЯ

В арифметичній прогресії ми додаємо одне й те саме число. У геометричній — множимо. Ця різниця принципова: АП зростає рівномірно (як сходи), а ГП — лавиноподібно (кожен крок більший за попередній). Саме тому ГП описує зростання населення, банківські відсотки, радіоактивний розпад.

4. Що таке геометрична прогресія?

Геометрична прогресія (ГП) — послідовність чисел (всі ненульові), у якій кожний наступний член отримується з попереднього множенням на одне й те саме число — знаменник прогресії q.

Аналогія: Бактерії або банківський відсоток

Бактерія ділиться кожну годину надвоє: 1, 2, 4, 8, 16, … (q=2). Або сума на рахунку зростає на 10% щороку — це геометрична прогресія.

Загальний виглядb₁, b₂, b₃, …, bₙ, …
де b₂ = b₁·q; b₃ = b₁·q²; …
q > 1Зростаюча (при b₁ > 0). Приклад: 2, 6, 18, 54, … (q=3)
0 < q < 1Спадаюча (при b₁ > 0). Приклад: 16, 8, 4, 2, 1, … (q=0,5)
q < 0Знакочергувальна. Приклад: 2, −4, 8, −16, … (q=−2)
q = 1Стала прогресія. Усі члени рівні b₁.

5. Формули геометричної прогресії

5.1 Формула n-го члена

bₙ = b₁ · qⁿ⁻¹

Приклад: Знайти 6-й член прогресії 3, 6, 12, 24, …

b₁ = 3, q = 2, n = 6

b₆ = 3 · 2⁵ = 3 · 32 = 96

Перевірка: 3, 6, 12, 24, 48, 96 — шостий член справді 96 ✓

5.2 Властивість членів ГП

bₙ² = bₙ₋₁ · bₙ₊₁

Кожний член ГП (крім крайніх) є середнім геометричним двох сусідніх членів: bₙ = √(bₙ₋₁ · bₙ₊₁).

Приклад: прогресія 2, 6, 18, 54. Перевіримо для b₂ = 6: √(b₁·b₃) = √(2·18) = √36 = 6 ✓. Якщо не сходиться — десь помилка в обчисленнях.

5.3 Сума перших n членів (q ≠ 1)

Sₙ = b₁ · (qⁿ − 1) / (q − 1)

При q = 1: Sₙ = b₁ · n

Приклад: Знайти суму перших 5 членів прогресії 2, 6, 18, …

b₁ = 2, q = 3, n = 5

S₅ = 2·(3⁵ − 1)/(3−1) = 2·(243−1)/2 = 242 → S₅ = 242

Перевірка: 2 + 6 + 18 + 54 + 162 = 242 ✓

5.4 Сума нескінченної геометричної прогресії (|q| < 1)

S∞ = b₁ / (1 − q), при |q| < 1

Якщо |q| < 1, кожен наступний член стає все меншим і прямує до нуля. Тоді сума нескінченної кількості членів — скінченне число. Це не інтуїтивно, але це факт.

Навіщо це потрібно? Наприклад, м'яч падає з висоти 2 м і після кожного відскоку піднімається на половину попередньої висоти: 2, 1, 0.5, 0.25, … Загальна відстань, яку пролетить м'яч = S∞ = 2/(1 − 0.5) = 4 м.

Приклад: 1 + 1/2 + 1/4 + 1/8 + … = ?

b₁ = 1, q = 1/2. S∞ = 1/(1−1/2) = 1/(1/2) = 2

! Умова існування S∞

Нескінченна сума ГП існує лише при |q| < 1. При |q| ≥ 1 сума прямує до нескінченності.

6. Як знайти невідомі елементи ГП

У формулі bₙ = b₁ · qⁿ⁻¹ — чотири величини. Якщо відомі будь-які три — четверту можна знайти:

Що відомоЩо знаходимоФормула
b₁, q, nbₙbₙ = b₁ · qⁿ⁻¹
b₁, bₙ, nqq = ⁿ⁻¹√(bₙ / b₁)
bₙ, q, nb₁b₁ = bₙ / qⁿ⁻¹

Приклад: b₁ = 4, b₄ = 108. Знайти q.

b₄ = b₁ · q³ → 108 = 4 · q³ → q³ = 27 → q = 3

Перевірка: 4, 12, 36, 108 — кожен наступний утричі більший ✓

Типові помилки

1. У формулі n-го члена пишуть qⁿ замість qⁿ⁻¹.
Неправильно: b₆ = 3·2⁶ = 192. Правильно: b₆ = 3·2⁵ = 96. Від першого до шостого — п'ять множень, а не шість.

2. Плутають q і bₙ.
Прогресія 2, 6, 18, 54. q = 6/2 = 3 (відношення сусідніх), а не q = 54. q знаходиться як b₂/b₁.

3. Використовують формулу S∞ при |q| ≥ 1.
Прогресія 1, 2, 4, 8, … (q = 2). Формула S∞ = 1/(1−2) = −1 — безглуздість. Формула працює тільки при |q| < 1!

4. Забувають, що q може бути від'ємним.
Прогресія 3, −6, 12, −24, … → q = −6/3 = −2. Знаки чергуються — це нормально для ГП з від'ємним q.
