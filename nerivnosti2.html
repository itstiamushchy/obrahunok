Лінійні та квадратні нерівності

ЧАСТИНА 2. ЛІНІЙНІ НЕРІВНОСТІ

Рівняння запитує «при якому x?» і дає одну відповідь. Нерівність запитує «при яких x?» і дає цілий проміжок — набір чисел, де умова виконується.

4. Що таке лінійна нерівність?

Лінійна нерівність — це нерівність вигляду ax + b > 0 (або з іншим знаком: ≥, <, ≤), де x — невідоме, а a і b — числа, причому a ≠ 0.

Загальний вигляд: ax + b > 0, ax + b ≥ 0, ax + b < 0, ax + b ≤ 0

Розв'язати нерівність — знайти всі значення x, при яких вона є істинною.

5. Алгоритм розв'язання лінійної нерівності

Розв'язання нерівності — це ті самі дії, що і для рівняння: переносимо, спрощуємо, ділимо. Одна відмінність: при діленні на від'ємне число знак нерівності перевертається.

  1. Перенесіть усі члени з x в ліву частину, числові — в праву.
    Чому? Щоб x опинився окремо, а числа — окремо. Це та сама властивість 2: додаємо однакове число до обох частин, знак не змінюється.
  2. Спростіть обидві частини (зведіть подібні члени).
  3. Поділіть обидві частини на коефіцієнт при x.
    Якщо коефіцієнт додатний — знак нерівності зберігається.
    Якщо коефіцієнт від'ємний — знак нерівності змінюється на протилежний! Чому? Бо ділення на від'ємне — це множення на від'ємне (властивість 4). Числова пряма «перевертається».
  4. Запишіть відповідь у вигляді нерівності або числового проміжку.

5.1 Приклад 1 (коефіцієнт додатний)

Розв'язати: 3x − 6 > 0

3x > 6 ⟹ x > 6/3 ⟹ x > 2

Відповідь: x ∈ (2; +∞)

5.2 Приклад 2 (коефіцієнт від'ємний — знак змінюється!)

Розв'язати: −2x + 4 ≥ 0

−2x ≥ −4 ⟹ ділимо на (−2), знак змінюється: x ≤ 2

Чому ≥ стало ≤? Ми ділимо обидві частини на −2. Це від'ємне число, тому знак перевертається (властивість 4).

Перевірка: x = 0 (має задовольняти, бо 0 ≤ 2): −2·0 + 4 = 4 ≥ 0 ✓
x = 3 (не має задовольняти, бо 3 > 2): −2·3 + 4 = −2, а −2 ≥ 0 — ні ✓

5.3 Приклад 3 (розгорнутий вигляд)

Розв'язати: 2x − 5 < 3x + 1

Крок 1. Переносимо x вліво, числа вправо. Чому 3x переноситься зі знаком мінус? Бо ми віднімаємо 3x від обох частин (властивість 2):
2x − 3x < 1 + 5
Крок 2. Спрощуємо: −x < 6
Крок 3. Ділимо на (−1), знак змінюється: x > −6

Відповідь: x ∈ (−6; +∞)

Перевірка: x = 0 (має бути > −6): 2·0 − 5 = −5, 3·0 + 1 = 1, −5 < 1 ✓

6. Запис відповіді — числові проміжки

Проміжок — це спосіб записати набір чисел, які є відповіддю. Замість слів «усі числа більші за 2» пишемо коротко: (2; +∞).

Як читати дужки: круглі дужки ( ) — точка НЕ входить (порожнє коло на прямій). Квадратні дужки [ ] — точка ВХОДИТЬ (зафарбоване коло). Нескінченність ∞ завжди з круглою дужкою — бо нескінченність не число, її не можна «включити».

x > a(a; +∞) — точка a не входить
x ≥ a[a; +∞) — точка a входить
x < a(−∞; a) — точка a не входить
x ≤ a(−∞; a] — точка a входить
a < x < b(a; b) — обидві точки не входять
a ≤ x ≤ b[a; b] — обидві точки входять

Порада: завжди перевіряйте відповідь — підставте будь-яке число з вашого проміжку в початкову нерівність (має бути правдивою) і будь-яке число поза проміжком (має бути хибною).
