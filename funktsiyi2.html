ЧАСТИНА 2. ВЛАСТИВОСТІ ФУНКЦІЙ

Знати формулу функції — мало. Потрібно розуміти, як вона поводиться: де зростає, де спадає, чи є симетрія, де перетинає осі. Ці характеристики називають властивостями функції. Вони дозволяють зрозуміти поведінку графіка, не будуючи його повністю.

3. Парність та непарність

Яку задачу це вирішує? Якщо функція парна або непарна, її графік має симетрію — а значить, достатньо побудувати лише половину графіка, друга половина відображається автоматично.

Як перевірити: підставити (−x) замість x і порівняти результат з f(x).

ТипУмоваЩо це означаєПриклади
Парнаf(−x) = f(x)Ліва і права частини графіка — дзеркальне відображення відносно осі OYy = x², y = cos x, y = |x|
Непарнаf(−x) = −f(x)Графік симетричний відносно початку координат (точка O)y = x³, y = sin x, y = 1/x
Загального виглядуЖодна умова не виконуєтьсяСиметрії немаєy = x + 1, y = 2ˣ

Спробуйте самі: рухайте повзунок — точки (x, f(x)) та (−x, f(−x)) рухаються по параболі y = x². Зверніть увагу: вони завжди на одній висоті — це і є парність.

2

Важлива умова!

Перш ніж перевіряти парність, переконайтесь, що область визначення симетрична відносно нуля: якщо x ∈ D(f), то і −x ∈ D(f). Якщо ні — функція не є ні парною, ні непарною. Наприклад, f(x) = √x має D(f) = [0; +∞) — не симетрична → ні парна, ні непарна.

4. Монотонність (зростання та спадання)

Яку задачу це вирішує? Монотонність показує, де функція збільшується, а де зменшується. Це потрібно для розв'язання нерівностей, пошуку найбільшого/найменшого значення і побудови графіка.

ВластивістьЩо відбуваєтьсяНа графіку
Зростає на (a; b)Більше x → більше y. Тобто якщо x₁ < x₂, то f(x₁) < f(x₂)Графік іде вгору зліва направо ↗
Спадає на (a; b)Більше x → менше y. Тобто якщо x₁ < x₂, то f(x₁) > f(x₂)Графік іде вниз зліва направо ↘
Стала на (a; b)y не змінюється при зміні xГоризонтальна пряма

Спробуйте самі: змінюйте коефіцієнт k у функції y = kx. При k > 0 пряма зростає, при k < 0 — спадає, при k = 0 — горизонтальна.

5. Нулі функції та знакові проміжки

Яку задачу це вирішує? Нулі функції — це точки, де графік перетинає вісь OX. Вони ділять числову пряму на проміжки, де функція або додатна (графік вище осі), або від'ємна (нижче осі). Це основа методу інтервалів для розв'язання нерівностей.

Що шукаємоЯк знайтиЩо це на графіку
Нулі функціїРозв'язати рівняння f(x) = 0Точки перетину графіка з віссю OX
f(x) > 0Визначити проміжки між нулями, де графік вище OXЧастини графіка над віссю OX
f(x) < 0Визначити проміжки між нулями, де графік нижче OXЧастини графіка під віссю OX

Приклад. f(x) = x² − 4. Нулі: x² − 4 = 0 → x = −2 та x = 2. Підставимо x = 0 (між нулями): f(0) = −4 < 0 → між −2 і 2 графік нижче осі. Підставимо x = 3 (за нулем): f(3) = 5 > 0 → за межами [−2; 2] графік вище осі.

6. Екстремуми — максимум і мінімум

Яку задачу це вирішує? Екстремуми — це «гірки» та «ямки» на графіку. Знаючи їх, можна визначити найбільше та найменше значення функції на проміжку.

МаксимумТочка, де функція переходить від зростання до спадання (вершина «гірки»)
МінімумТочка, де функція переходить від спадання до зростання (дно «ямки»)

Приклад. y = −x² + 4x − 3. Це парабола з вітками вниз (a = −1 < 0), тому вершина — це максимум. Вершина: x = −b/(2a) = −4/(−2) = 2, y = −4 + 8 − 3 = 1. Максимум функції: y = 1 при x = 2.

7. Обмеженість

Яку задачу це вирішує? Якщо функція обмежена — її значення не можуть бути як завгодно великими (або малими). Це важливо для задач на найбільше/найменше значення.

Обмежена зверхуЄ таке число M, вище якого графік не піднімається: f(x) ≤ M для всіх x
Обмежена знизуЄ таке число m, нижче якого графік не опускається: f(x) ≥ m для всіх x
ОбмеженаОбмежена і зверху, і знизу — графік «живе» в горизонтальній смузі

Приклади: y = sin x — обмежена: −1 ≤ sin x ≤ 1. y = x² — обмежена знизу (y ≥ 0), але не зверху. y = x³ — не обмежена ні зверху, ні знизу.

8. Неперервність та асимптоти

Неперервна функція — це функція, графік якої можна намалювати не відриваючи олівця від паперу. Більшість функцій, з якими ви працюєте (многочлени, синус, косинус), — неперервні.

Розрив виникає там, де функція не визначена. Наприклад, f(x) = 1/x має розрив при x = 0 (ділити на нуль не можна).

Спробуйте самі: наближайте x до нуля на графіку y = 1/x — значення y різко зростає. Пряма x = 0, до якої графік наближається, але ніколи не торкається, називається вертикальною асимптотою.

2.0

Вертикальна асимптотаПряма x = a, до якої графік наближається, коли y → ±∞. Виникає в точках, де знаменник = 0
Горизонтальна асимптотаПряма y = b, до якої графік наближається при x → ±∞. Показує, до якого значення «прагне» функція на нескінченності

Типові помилки

1. Перевіряють парність без перевірки D(f).
f(x) = √x. Підставляють: f(−x) = √(−x) — не існує для додатних x. Але замість висновку «D(f) не симетрична → ні парна, ні непарна» пишуть «непарна». Спершу перевірте D(f)!

2. Плутають «зростає в точці» і «зростає на проміжку».
y = x² спадає на (−∞; 0) і зростає на (0; +∞). Не можна сказати «y = x² зростає» без вказування проміжку — на різних ділянках вона поводиться по-різному.

3. Плутають екстремум і найбільше значення.
Екстремум — це локальне поняття: найвища точка серед сусідніх. Найбільше значення на відрізку може бути на кінці відрізка, а не в екстремумі. Наприклад, y = x на [0; 10] зростає, максимум на кінці x = 10, екстремумів немає.

4. Забувають, що вертикальна асимптота — це не точка графіка.
y = 1/x при x = 0 — не має значення (ділити на нуль не можна). Графік наближається до прямої x = 0, але ніколи її не перетинає.
