ЧАСТИНА 1. СИСТЕМА КООРДИНАТ У ПРОСТОРІ

У площині точка має 2 координати (x; y). У просторі додається третя — z (висота). Усі формули з координатної геометрії на площині працюють і тут — просто додається ще один доданок під коренем або ще одна координата.

1. Прямокутна (декартова) система координат

Три взаємно перпендикулярні осі: OX, OY, OZ. Кожна точка: M(x; y; z).

Координатні площиниXOY (z=0); XOZ (y=0); YOZ (x=0) — ділять простір на 8 октантів
Відстань до площинДо XOY: |z|. До XOZ: |y|. До YOZ: |x|
Відстань до осейДо OX: √(y²+z²). До OY: √(x²+z²). До OZ: √(x²+y²)

2. Основні формули

Що шукаємоФормулаПриклад: A(1;2;3), B(4;6;3)
Відстань |AB|√((x₂−x₁)²+(y₂−y₁)²+(z₂−z₁)²)√(9+16+0) = √25 = 5
Середина M((x₁+x₂)/2; (y₁+y₂)/2; (z₁+z₂)/2)M(2.5; 4; 3)

3. Рівняння прямої

Пряма у просторі задається точкою M₀(x₀; y₀; z₀) і напрямним вектором d→ = (l; m; n):

Параметричнеx = x₀ + lt; y = y₀ + mt; z = z₀ + nt, t ∈ ℝ
Канонічне(x−x₀)/l = (y−y₀)/m = (z−z₀)/n
Паралельні пряміd→₁ = λ·d→₂ (напрямні колінеарні)
Перпендикулярніd→₁ · d→₂ = 0 (скалярний добуток = 0)
Кут між прямимиcos φ = |d→₁ · d→₂| / (|d→₁| · |d→₂|)

Приклад: Пряма через M(1; 2; 3) з напрямним d→ = (2; −1; 3):

Канонічне: (x−1)/2 = (y−2)/(−1) = (z−3)/3

Параметричне: x = 1+2t, y = 2−t, z = 3+3t

ЧАСТИНА 3. ПЛОЩИНА У ПРОСТОРІ

4. Рівняння площини

Площина задається нормальним вектором n→ = (A; B; C), перпендикулярним до неї:

Ax + By + Cz + D = 0

Через точку і нормальA(x−x₀) + B(y−y₀) + C(z−z₀) = 0
Через 3 точкиДва вектори у площині → їхній векторний добуток = нормаль n→
Відстань від точкиd = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²)
Паралельні площиниA₁/A₂ = B₁/B₂ = C₁/C₂
ПерпендикулярніA₁A₂ + B₁B₂ + C₁C₂ = 0
Кут між площинамиcos φ = |A₁A₂+B₁B₂+C₁C₂| / (√(A₁²+B₁²+C₁²)·√(A₂²+B₂²+C₂²))

Приклад: Відстань від точки (1; 0; −2) до площини 2x − y + 2z − 6 = 0:

d = |2·1 + (−1)·0 + 2·(−2) − 6| / √(4+1+4) = |2+0−4−6| / 3 = 8/3 ≈ 2.67

ЧАСТИНА 4. ІНШІ СИСТЕМИ КООРДИНАТ

5. Циліндричні координати

Формулиx = r·cos φ; y = r·sin φ; z = z
rВідстань від точки до осі OZ
φКут у площині XOY від осі OX (0 ≤ φ < 2π)
zВисота (як у декартовій)

6. Сферичні координати

Формулиx = r·sinθ·cosφ; y = r·sinθ·sinφ; z = r·cosθ
rВідстань від початку координат до точки
θЗенітний кут (від осі OZ, 0 ≤ θ ≤ π)
φАзимутальний кут (у площині XOY, 0 ≤ φ < 2π)
Зв'язокГеографія: широта = 90°−θ, довгота = φ

Типові помилки

1. Забувають третю координату.
Відстань у просторі: √(Δx²+Δy²+Δz²), не √(Δx²+Δy²). Середина: три координати, не дві.

2. Плутають рівняння прямої (2D) і площини (3D).
Ax+By+C=0 на площині — пряма. Ax+By+Cz+D=0 у просторі — площина. Пряма у просторі задається двома рівняннями або параметрично.

3. У формулі відстані до площини забувають +D.
d = |Ax₀+By₀+Cz₀+D|/√(A²+B²+C²). D — вільний член рівняння площини, не можна його пропускати.

Координати у просторі — фундамент 3D-геометрії.
