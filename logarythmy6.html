ЧАСТИНА 6. ПІДСУМОК — ПАМ'ЯТКА

Ця пам'ятка — для швидкого повторення перед НМТ. Усі формули і правила логарифмів в одному місці.

Показникові рівняння через логарифм

Якщо показникове рівняння не зводиться до однієї основи — логарифмуємо обидві частини:

ВиглядРозв'язок
aˣ = bx = logₐb = lg b / lg a
a^(f(x)) = bf(x) = logₐb → розв'язати відносно x

Приклад 1: 2ˣ = 5

КрокДіяРезультат
Логарифмуємоx·lg 2 = lg 5x = lg 5 / lg 2
Обчислюємо0.699 / 0.301x ≈ 2.322

Перевірка: 2^2.322 ≈ 5.00 ✓

Приклад 2: 3^(2x+1) = 7

КрокДіяРезультат
Логарифмуємо(2x+1)·lg 3 = lg 72x + 1 = lg 7 / lg 3
Обчислюємо lg7/lg30.845 / 0.477 ≈ 1.7712x + 1 = 1.771
Знаходимо x2x = 0.771x ≈ 0.386

Перевірка: 3^(2·0.386+1) = 3^1.771 ≈ 7.0 ✓

Означення та умови

logₐb = x ⟺ aˣ = bОсновне означення
a > 0, a ≠ 1Умова на основу
b > 0Умова на аргумент (строго!)
lg b = log₁₀bДесятковий логарифм
ln b = logₑbНатуральний логарифм (e ≈ 2.718)

Тотожності

logₐaˣ = xlogₐ1 = 0logₐa = 1a^(logₐb) = b

Властивості

ДіяФормулаНапрямок
Добутокlogₐ(M·N) = logₐM + logₐN↔
Часткаlogₐ(M/N) = logₐM − logₐN↔
Степіньlogₐ(Mⁿ) = n·logₐM↔
Коріньlogₐ(ⁿ√M) = (1/n)·logₐM↔
Перехід основиlogₐb = log_c(b) / log_c(a)→
Оберненняlogₐb = 1 / log_b(a)→

logₐ(M + N) ≠ logₐM + logₐN — логарифм суми НЕ розкладається! Тільки добуток і частка.

Рівняння — методи

Що бачишМетодФормула
logₐ(…) = logₐ(…)Прирівняти аргументиf(x) = g(x), ОДЗ: f > 0, g > 0
logₐ(…) = числоПотенціюванняf(x) = aᵇ
(logₐx)² або кілька logₐxЗаміна t = logₐxКвадратне відносно t
aˣ = b (не зводиться)Логарифмуванняx = lg b / lg a

Нерівності — правило знака

a > 1Знак зберігаєтьсяlogₐf(x) > logₐg(x) → f(x) > g(x)
0 < a < 1Знак змінюєтьсяlogₐf(x) > logₐg(x) → f(x) < g(x)

+ завжди перетинаємо з ОДЗ!

Чеклист перед відповіддю

☐ ОДЗ записано? Аргументи > 0, основа > 0 і ≠ 1?
☐ Властивості застосовані правильно? (Добуток, не сума!)
☐ Основи однакові перед прирівнюванням аргументів?
☐ У нерівності врахований знак основи (a > 1 чи a < 1)?
☐ Відповідь перетнута з ОДЗ?
☐ Перевірка підстановкою в початкове рівняння/нерівність?

Типові помилки — зведення

1. log від 0 або від'ємного числа не існує.

2. logₐ(M+N) ≠ logₐM + logₐN. Тільки добуток/частка!

3. n·logₐM = logₐMⁿ (степінь аргументу, не множник).

4. При основі < 1 знак нерівності змінюється.

5. Після об'єднання логарифмів зберігайте початкове ОДЗ.

6. Число перетворюйте в логарифм тієї ж основи: 2 = log₃9, а не «прибираємо log».

Логарифми — це обернена операція до степеня. Якщо це зрозуміти — все інше є наслідком.
