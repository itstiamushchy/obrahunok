ЧАСТИНА 6. ТРИГОНОМЕТРИЧНІ РІВНЯННЯ

Тригонометричні рівняння відрізняються від усіх попередніх: вони мають не один і не два розв'язки, а нескінченно багато. Чому? Бо тригонометричні функції повторюються — sin і cos мають період 2π, tg — період π. Кожен оберт по колу дає новий розв'язок.

13. Основні тригонометричні рівняння

Тригонометричні рівняння мають нескінченно багато коренів (через periodicity функцій). Відповідь записується загальною формулою.

sin x = a• Якщо |a| ≤ 1:
x = (−1)ⁿ arcsin(a) + πn, n ∈ ℤ
Приклад: sin x = 1/2 → x = π/6 + 2πn або x = 5π/6 + 2πn

Чому два «сімейства»? arcsin(a) дає один кут, але sin однаковий у двох точках кола (наприклад sin 30° = sin 150° = 1/2). А +2πn додає кожен наступний оберт.
• Якщо |a| > 1: коренів немає — sin приймає значення тільки від −1 до 1
cos x = a• Якщо |a| ≤ 1:
x = ±arccos(a) + 2πn, n ∈ ℤ
Приклад: cos x = 0 → x = π/2 + πn

Чому ±? Бо cos однаковий для кута і для того самого кута з мінусом: cos 60° = cos(−60°) = 1/2. Симетрія відносно осі x.
• Якщо |a| > 1: коренів немає — cos теж тільки від −1 до 1
tg x = ax = arctg(a) + πn, n ∈ ℤ
Приклад: tg x = 1 → x = π/4 + πn
Формула простіша: tg повторюється кожні π (не 2π). Один кут — і додаємо πn. Обмеження |a| ≤ 1 немає — tg може бути будь-яким числом.
ctg x = ax = arcctg(a) + πn, n ∈ ℤ
Приклад: ctg x = 1 → x = π/4 + πn
Та сама логіка, що й для tg — період π.

Як розв'язувати тригонометричні рівняння — покрокова інструкція

Крок 1. Визначте тип:
Рівняння вже у вигляді sin x = a, cos x = a, tg x = a? → одразу до кроку 3.
Якщо ні → спочатку спростити (крок 2).

Крок 2. Зведіть до базового вигляду:
— Все одна функція (тільки sin)? → виразіть sin x = число
— Є sin² і cos²? → замініть cos²x = 1 − sin²x (або навпаки), отримаєте квадратне рівняння
— Є sin і cos разом? → спробуйте формули подвійного кута або поділіть на cos x (отримаєте tg x)
— Складний аргумент (sin 2x, cos(x + π/3))? → заміна t = 2x або t = x + π/3, розв'яжіть для t, потім знайдіть x

Крок 3. Запишіть загальну формулу
sin → arcsin + πn, cos → ±arccos + 2πn, tg → arctg + πn

Крок 4. Якщо потрібні розв'язки на проміжку [0; 2π):
підставляйте n = 0, 1, −1, 2... поки x потрапляє в проміжок

Крок 5. Перевірка — підставте хоча б один корінь у початкове рівняння
