ЧАСТИНА 3. ОСНОВНІ ФУНКЦІЇ ТА ЇХ ГРАФІКИ (1/2)

У цій частині розглянемо чотири базові типи функцій: лінійну, квадратичну, многочлени вищих степенів та степеневу функцію. Для кожної — формула з усіма параметрами, таблиця властивостей та інтерактивний графік: рухайте повзунки і дивіться, як параметри впливають на форму кривої.

8. Лінійна функція: y = kx + b

Найпростіша функція — графік завжди пряма лінія. Два параметри повністю визначають її поведінку:

ПараметрЩо робитьЯк бачити на графіку
k — кутовий коефіцієнтВизначає нахил прямоїk > 0: зростає ↗   k < 0: спадає ↘   k = 0: горизонтальна
b — вільний членЗсуває пряму вгору або внизТочка перетину з віссю OY: (0; b)
D(f)ℝ (усі дійсні числа)
E(f)ℝ (якщо k ≠ 0); {b} (якщо k = 0)
Нуль функціїx = −b/k (якщо k ≠ 0)
ПарністьНепарна лише при b = 0; інакше — загального вигляду

9. Квадратична функція: y = ax² + bx + c

Графік — парабола. Три параметри визначають її форму і положення:

ПараметрЩо робитьЯк бачити на графіку
aНапрям і ширина параболиa > 0: вітки вгору (∪)   a < 0: вітки вниз (∩)
|a| великий → вузька, |a| малий → широка
bЗсуває вершину по горизонталі (разом з a)Вершина: x₀ = −b/(2a)
cЗсуває параболу вгору/внизТочка перетину з OY: (0; c)
Вершинаx₀ = −b/(2a),   y₀ = a·x₀² + b·x₀ + c
Вісь симетріїx = −b/(2a)
D(f)ℝ
E(f)[y₀; +∞) при a > 0;   (−∞; y₀] при a < 0
НуліD = b² − 4ac.   D > 0: два нулі; D = 0: один; D < 0: немає
ПарністьПарна лише при b = 0 (вісь симетрії = OY)

10. Многочлени вищих степенів

Лінійна та квадратична функції — це многочлени 1-го та 2-го степеня. Закономірність продовжується:

СтепіньЗагальний виглядНазва графіка
1y = ax + bПряма
2y = ax² + bx + cПарабола
3y = ax³ + bx² + cx + dКубічна крива
ny = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀Многочлен n-го степеня

Кожен наступний степінь додає один коефіцієнт і змінює форму графіка. Кубічна функція y = ax³ + bx² + cx + d може мати до двох «згинів» (екстремумів) і до трьох нулів.

y = ax³ + bx² + cx + d

11. Степенева функція: y = a·xⁿ

Це окремий випадок!

Степенева функція y = a·xⁿ — це многочлен, у якого лише один доданок (старший). У ній немає доданків з xⁿ⁻¹, xⁿ⁻², … , x, і вільного члена — вони всі дорівнюють нулю. Це не замінює повну форму многочлена, а показує, як поводиться «чистий» степінь.

Поведінка суттєво залежить від того, парне n чи непарне:

nГрафікСиметріяПоведінка
Парне (2, 4, 6…)ПараболоподібнийПарна: f(−x) = f(x)При a > 0: мінімум у x = 0, вітки вгору
Непарне (1, 3, 5…)S-подібнийНепарна: f(−x) = −f(x)При a > 0: зростає на всьому ℝ
D(f)ℝ (для цілих додатних n)
E(f)n парне, a > 0: [0; +∞). n непарне: ℝ
Нуль функціїЗавжди x = 0 (єдиний)

Не плутайте! y = 2x³ — степенева (один доданок). y = 2x³ + x² − 3x + 1 — многочлен 3-го степеня (чотири доданки). Степенева функція — це окремий випадок многочлена, а не його загальна форма.
