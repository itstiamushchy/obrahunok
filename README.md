## Опис

**Обрахунок** — повноцінний інтерактивний довідник з математики у форматі статичного вебсайту. Працює без серверної частини — достатньо відкрити `index.html` у браузері або розмістити на GitHub Pages.

Призначений для підготовки до НМТ, ЗНО, шкільних іспитів та самостійного вивчення математики.

## Розділи

### 📖 Теорія (57 лекцій)

Лекційний матеріал з повними поясненнями, прикладами, таблицями та візуалізаціями.

| Галузь | Розділи | Лекцій |
|--------|---------|--------|
| Алгебра | 1–7 (числа, вирази, нерівності, рівняння, функції, прогресії, логарифми) | 38 |
| Геометрія | 8–13 (основи, трикутники, чотирикутники, коло, площі, стереометрія) | 6 |
| Тригонометрія | 14–17 (одиничне коло, формули, рівняння, обернені функції) | 4 |
| Аналітична геометрія | 18–21 (вектори, координати, конічні перерізи, простір) | 4 |
| Аналіз | 22–26 (комбінаторика, ймовірність, похідна, інтеграл, ряди) | 5 |

**Навігація:** sidebar з деревом тем + кнопки «← Попередня / Наступна →» внизу кожної лекції.

### 📐 Формули (45 формул)

Кожна формула — окрема картка з полями:

- **Формула** — чітке відображення
- **Розділ** — до якої галузі належить + посилання на теорію
- **Визначає** — що описує формула
- **Застосування** — практичне використання
- **Приклад** — числовий приклад
- **Рекомендація** — поради та мнемоніки
- **Застереження** — типові помилки

**Навігація:** фільтр по розділах (пілюлі) + пошук.

### 📝 Задачник (754 задачі)

50 тематичних блоків, 15 задач у кожному, 5 рівнів складності:

| Рівень | Назва | Колір |
|--------|-------|-------|
| 1 | Початковий | 🟢 |
| 2 | Базовий | 🔵 |
| 3 | Середній | 🟠 |
| 4 | Складний | 🔴 |
| 5 | Олімпіадний | 🟣 |

Кожна задача містить:
- **Умову**
- **Підказки** (поетапне розкриття)
- **Покроковий розв'язок** (дія → пояснення → результат)
- **Відповідь**

Кожен блок задач має посилання на відповідний лекційний матеріал.

## Технології

- **HTML5 + CSS3 + Vanilla JS** — без фреймворків та залежностей
- **CSS Custom Properties** — світла/темна тема
- **CSS Grid + Flexbox** — адаптивна верстка
- **Responsive design** — повна підтримка мобільних пристроїв (breakpoint 768px)
- **localStorage** — збереження обраної теми
- **Fetch API** — динамічне завантаження JSON-задач

## Розгортання

### Локально

Просто відкрийте `index.html` у браузері. Задачник потребує HTTP-сервера (через fetch):

```bash
cd obrahunok
python3 -m http.server 8000
# відкрийте http://localhost:8000
```

### GitHub Pages

1. Завантажте папку `obrahunok/` у репозиторій
2. Settings → Pages → Source: Deploy from a branch → `main` / `root`
3. Сайт доступний за адресою `https://<username>.github.io/<repo>/`
