ЧАСТИНА 4. ЛОГАРИФМІЧНІ РІВНЯННЯ

Логарифмічне рівняння — це рівняння, в якому невідома стоїть під знаком логарифма. Головна особливість: перш ніж розв'язувати — записати ОДЗ (область допустимих значень). Без цього можна отримати сторонні корені.

7. Як обрати метод

Що бачиш у рівнянніМетодІди до
logₐ(…) = logₐ(…) — однакові основиЗведення до однієї основиМетод 1
logₐ(…) = числоПотенціюванняМетод 2
(logₐx)² або кілька logₐx разомЗаміна t = logₐxМетод 3
Логарифми різних основФормула переходу → один із методів вищеЧастина 7.2

Метод 1: Зведення до однієї основи

Ідея: якщо logₐf(x) = logₐg(x), то f(x) = g(x) (логарифми «скорочуються»).

Умова: f(x) > 0 і g(x) > 0 — це і є ОДЗ.

Приклад: log₃(2x − 1) = log₃(x + 4)

КрокДіяРезультат
1. ОДЗ2x − 1 > 0 і x + 4 > 0x > 0.5 і x > −4 → x > 0.5
2. Прирівнюємо аргументи2x − 1 = x + 4x = 5
3. Перевірка ОДЗ5 > 0.5✓ входить
4. Перевірка підстановкоюlog₃(10−1) = log₃(5+4) → log₃9 = log₃9✓ вірно

Відповідь: x = 5

Метод 2: Потенціювання

Ідея: якщо logₐf(x) = b, то f(x) = aᵇ (переходимо від логарифма до степеня).

Приклад: log₂(x² − 3x) = 2

КрокДіяРезультат
1. ОДЗx² − 3x > 0 → x(x−3) > 0x < 0 або x > 3
2. Потенціюємоx² − 3x = 2² = 4x² − 3x − 4 = 0
3. Розв'язуємо квадратнеD = 9 + 16 = 25, √D = 5x = 4 або x = −1
4. Перевірка ОДЗx = 4: 4 > 3 ✓   x = −1: −1 < 0 ✓Обидва входять
5. Перевірка підстановкоюx=4: log₂(16−12)=log₂4=2 ✓
x=−1: log₂(1+3)=log₂4=2 ✓		Обидва вірні

Відповідь: x = −1, x = 4

Метод 3: Заміна змінної

Ідея: якщо logₐx зустрічається у рівнянні кілька разів — позначаємо t = logₐx і отримуємо звичайне рівняння (зазвичай квадратне).

Приклад: (log₃x)² − 4·log₃x + 3 = 0

КрокДіяРезультат
1. ОДЗx > 0x > 0
2. Замінаt = log₃xt² − 4t + 3 = 0
3. Квадратне рівнянняD = 16 − 12 = 4t = 1 або t = 3
4. Повертаємо замінуt=1: log₃x=1 → x=3
t=3: log₃x=3 → x=27		x = 3, x = 27
5. Перевірка ОДЗ3 > 0 ✓, 27 > 0 ✓Обидва входять
6. Перевірка підстановкоюx=3: 1−4+3=0 ✓
x=27: 9−12+3=0 ✓		Обидва вірні

Відповідь: x = 3, x = 27

Алгоритм розв'язання будь-якого логарифмічного рівняння

1. Записати ОДЗ: усі аргументи логарифмів > 0
2. Спростити (властивості з частини 7.2–7.3)
3. Звести до одного з трьох методів
4. Розв'язати
5. Перевірити кожен корінь в ОДЗ — сторонні відкидаємо
6. Перевірити підстановкою в початкове рівняння

Типові помилки

1. Забули ОДЗ — прийняли сторонній корінь.
log₂(x−3) + log₂(x+1) = 3 → log₂((x−3)(x+1)) = 3 → (x−3)(x+1) = 8 → x²−2x−11 = 0 → x ≈ 4.46 або x ≈ −2.46. Але x = −2.46 не входить в ОДЗ (x−3 < 0) → відкидаємо.

2. Після об'єднання логарифмів «забувають» окремі ОДЗ.
log₂(x−1) + log₂(x+1) = log₂((x−1)(x+1)). ОДЗ: x > 1 і x > −1, тобто x > 1. Але (x−1)(x+1) > 0 виконується і при x < −1 — це хибне розширення ОДЗ. Зберігайте початкове ОДЗ!

3. Потенціюють рівняння з двома логарифмами.
log₂(x+1) = log₃(x+5). Не можна прирівняти аргументи (основи різні!). Спочатку — формула переходу до однієї основи.
