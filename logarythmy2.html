ЧАСТИНА 2. ВЛАСТИВОСТІ ЛОГАРИФМІВ

Логарифми мають набір властивостей, які дозволяють спрощувати складні вирази — перетворювати добутки на суми, ділення на різниці, «витягувати» показники степенів. Без цих властивостей розв'язувати логарифмічні рівняння практично неможливо.

3. Основні тотожності

Тотожності — це рівності, які виконуються завжди (при допустимих значеннях). Вони потрібні для швидкого спрощення: побачив logₐaˣ — одразу пишеш x, без обчислень.

Тотожність 1logₐaˣ = x (логарифм і степінь скорочуються)
Приклад: log₃3⁵ = 5
Тотожність 2a^(logₐb) = b (основа в степені логарифма = аргумент)
Приклад: 2^(log₂7) = 7
logₐ1 = 0Будь-яка основа у степені 0 = 1
Приклад: log₅1 = 0
logₐa = 1Логарифм основи за цією самою основою = 1
Приклад: log₇7 = 1

4. Властивості дій з логарифмами

Умова для всіх: a > 0, a ≠ 1; всі аргументи > 0.

Логарифм добуткуlogₐ(M·N) = logₐM + logₐN
Приклад: log₂(4·8) = log₂4 + log₂8 = 2 + 3 = 5
Логарифм часткиlogₐ(M/N) = logₐM − logₐN
Приклад: log₃(81/9) = log₃81 − log₃9 = 4 − 2 = 2
Логарифм степеняlogₐ(Mⁿ) = n · logₐM
Приклад: log₂(8³) = 3·log₂8 = 3·3 = 9
Логарифм кореняlogₐ(ⁿ√M) = (1/n)·logₐM
Приклад: log₄(√16) = (1/2)·log₄16 = (1/2)·2 = 1
Степінь коефіцієнта перед logₐn·logₐM = logₐMⁿ (обернена до властивості степеня)
Корисно для спрощення виразів

! Типові помилки

logₐ(M+N) ≠ logₐM + logₐN — логарифм суми НЕ розкладається!
logₐ(M−N) ≠ logₐM − logₐN — логарифм різниці теж НЕ розкладається!
Правила стосуються лише множення і ділення під логарифмом.

Приклад: спрощення складного виразу

Спростити: log₂12 − log₂3 + 2·log₂2

  1. log₂12 − log₂3 = log₂(12/3) = log₂4   (логарифм частки)
  2. 2·log₂2 = log₂2² = log₂4   (коефіцієнт → степінь)
  3. log₂4 + log₂4 = log₂(4·4) = log₂16 = 4   (логарифм добутку)

Перевірка: log₂12 ≈ 3.585, log₂3 ≈ 1.585, 2·log₂2 = 2. Сума: 3.585 − 1.585 + 2 = 4 ✓

5. Формула переходу до іншої основи

logₐb = log_c(b) / log_c(a)

Зокрема, якщо перейти до основи b:

logₐb = 1 / log_b(a)

Навіщо це потрібно?

Якщо у виразі логарифми різних основ — зводимо їх до однієї (зазвичай до lg або ln) і рахуємо.

Приклади:

log₄8 = log₂8 / log₂4 = 3/2

log₉27 = log₃27 / log₃9 = 3/2

log₂5 · log₅4 = log₂5 · (log₂4/log₂5) = log₂4 = 2

Типові помилки

1. Розкладають логарифм суми.
Неправильно: log₂(4 + 8) = log₂4 + log₂8 = 2 + 3 = 5. Правильно: log₂(4 + 8) = log₂12 ≈ 3.585. Властивість працює тільки для добутку і частки!

2. Забувають перевірити ОДЗ після спрощення.
log₂(x−1) + log₂(x+1) = log₂((x−1)(x+1)). Але ОДЗ вимагає x−1 > 0 і x+1 > 0, тобто x > 1. Після об'єднання в один логарифм ОДЗ «ховається» — не забувайте його.

3. Плутають напрямок формули переходу.
logₐb = log_c(b) / log_c(a). У знаменнику — логарифм основи (а), не аргументу. Мнемоніка: основа «спускається» вниз у дріб.
