ЧАСТИНА 1. ОСНОВИ

Трикутник — найпростіший многокутник і найважливіша фігура в геометрії. Будь-який многокутник можна розбити на трикутники, тому всі формули площ, кутів і відстаней зрештою зводяться до трикутників. На НМТ це одна з найчастіших тем.

1. Трикутник — визначення

Трикутник ABC — геометрична фігура, утворена трьома точками (вершинами A, B, C), не лежачими на одній прямій, і трьома відрізками (сторонами AB, BC, CA), що їх з'єднують.

СторониПозначаються малими літерами, протилежними вершині: a = BC (навпроти A), b = CA (навпроти B), c = AB (навпроти C)
Кути∠A (при вершині A), ∠B (при вершині B), ∠C (при вершині C)
АБО: α, β, γ
ПериметрP = a + b + c

Головна властивість

∠A + ∠B + ∠C = 180°

Сума кутів будь-якого трикутника = 180°. Це фундаментальний факт планіметрії!

2. Класифікація за кутами

ГостокутнийВсі три кути гострі (менші за 90°)
ПрямокутнийОдин кут прямий (= 90°). Сторона навпроти — гіпотенуза, дві інші — катети
ТупокутнийОдин кут тупий (більший за 90°)

3. Класифікація за сторонами

РізностороннійУсі три сторони різної довжини. Ніяких особливих властивостей кутів
РівнобедренийДві сторони рівні (бічні сторони). Кути при основі рівні.
Основа — третя (різна) сторона
РівностороннійВсі три сторони рівні. Всі кути = 60°. Є і рівнобедреним

ЧАСТИНА 2. ОЗНАКИ РІВНОСТІ ТРИКУТНИКІВ

4. Три ознаки рівності

Два трикутники рівні, якщо вони мають однакову форму і розмір (можна «накласти» один на одного). Для доведення рівності достатньо однієї з трьох ознак:

Ознака 1 (ст-ст-ст)Три сторони одного трикутника рівні трьом сторонам іншого:
AB = A₁B₁, BC = B₁C₁, AC = A₁C₁ ⟹ △ABC = △A₁B₁C₁
Ознака 2 (ст-кут-ст)Дві сторони і кут між ними рівні:
AB = A₁B₁, ∠B = ∠B₁, BC = B₁C₁ ⟹ △ABC = △A₁B₁C₁
Ознака 3 (кут-ст-кут)Сторона і два кути при ній рівні:
∠A = ∠A₁, AB = A₁B₁, ∠B = ∠B₁ ⟹ △ABC = △A₁B₁C₁

! Зверніть увагу

Ознака кут-кут-кут НЕ є ознакою рівності — однакові кути означають подібність, але не обов'язково рівність (можуть бути різного розміру).

ЧАСТИНА 3. ОСОБЛИВІ ЛІНІЇ ТРИКУТНИКА

5. Медіана, висота, бісектриса, серединний перпендикуляр

МедіанаВідрізок з вершини до середини протилежної сторони.
• Трикутник ділить на 2 рівновеликих

ЧАСТИНА 4. ПОДІБНІСТЬ ТРИКУТНИКІВ

6. Подібні трикутники

Подібні трикутники — трикутники, у яких кути рівні, а сторони пропорційні. Коефіцієнт подібності k = відношення відповідних сторін.

Ознака 1 (кут-кут)Два кути одного рівні двом кутам іншого:
∠A = ∠A₁, ∠B = ∠B₁ ⟹ △ABC ∼ △A₁B₁C₁
Ознака 2 (ст-ст-ст)Всі три пари відповідних сторін пропорційні:
a/a₁ = b/b₁ = c/c₁ = k
Ознака 3 (ст-кут-ст)Два відповідних боки пропорційні і кут між ними рівний:
a/a₁ = b/b₁ і ∠C = ∠C₁

Властивість подібних трикутників:

Відношення площ подібних трикутників = k² (квадрат коефіцієнта подібності).
Відношення периметрів = k (сам коефіцієнт).

ЧАСТИНА 5. ТЕОРЕМА ПІФАГОРА

7. Теорема Піфагора

У прямокутному трикутнику квадрат гіпотенузи дорівнює сумі квадратів катетів:

a² + b² = c²

де c — гіпотенуза (сторона навпроти прямого кута), a і b — катети

Приклад: Катети прямокутного трикутника: a = 6, b = 8. Знайти гіпотенузу.

c² = 6² + 8² = 36 + 64 = 100 → c = √100 = 10

Перевірка: це трійка (6, 8, 10) = 2×(3, 4, 5) ✓

Приклад: Гіпотенуза c = 13, катет a = 5. Знайти другий катет.

b = √(c² − a²) = √(169 − 25) = √144 = 12

Перевірка: 5² + 12² = 25 + 144 = 169 = 13² ✓

Наслідки теореми Піфагора:

a = √(c² − b²) та b = √(c² − a²)

9. Зворотня теорема Піфагора

Якщо у трикутнику зі сторонами a, b, c виконується a² + b² = c², то цей трикутник — прямокутний, а кут навпроти сторони c — прямий.

11. Теорема синусів і теорема косинусів

Теорема синусів

Для довільного трикутника ABC зі сторонами a, b, c і кутами α, β, γ:

a/sin α = b/sin β = c/sin γ = 2R

де R — радіус описаного кола

Застосування теореми синусів:

Знаємо один кут і одну сторону (та ще щось) → знаходимо невідоме.
Особливо зручна, коли дано кут-сторона-кут або кут-кут-сторона.

Теорема косинусів

c² = a² + b² − 2ab·cos γ

Узагальнення теореми Піфагора: при γ=90° маємо c²=a²+b²

Застосування теореми косинусів:

• Дано три сторони → знайти будь-який кут
• Дано дві сторони і кут між ними → знайти третю сторону
• Якщо cos γ > 0 → γ < 90° (гостро). cos γ < 0 → γ > 90° (тупо)

Приклад (теорема косинусів): У трикутнику a = 5, b = 7, γ = 60°. Знайти c.

c² = 5² + 7² − 2·5·7·cos 60° = 25 + 49 − 70·(1/2) = 74 − 35 = 39

c = √39 ≈ 6.24

Приклад (теорема синусів): У трикутнику a = 10, α = 30°, β = 45°. Знайти b.

a/sin α = b/sin β → 10/sin 30° = b/sin 45° → 10/(1/2) = b/(√2/2) → 20 = b·2/√2

b = 20·√2/2 = 10√2 ≈ 14.14

Типові помилки

1. Плутають катет і гіпотенузу в теоремі Піфагора.
Гіпотенуза — завжди найдовша сторона, навпроти прямого кута. a² + b² = c², де c — гіпотенуза. Якщо записати c² + b² = a², де a — катет, результат буде хибним.

2. Плутають протилежний і прилеглий катет.
sin α = протилежний/гіпотенуза, cos α = прилеглий/гіпотенуза. «Протилежний» — це той, що навпроти кута α, а не поруч з ним.

3. Ознака кут-кут-кут доводить подібність, а не рівність.
Два трикутники з однаковими кутами — подібні (однакова форма), але можуть мати різні розміри. Для рівності потрібна хоча б одна сторона.

4. Забувають мінус у теоремі косинусів.
c² = a² + b² − 2ab·cos γ. Знак мінус! Якщо γ — тупий, то cos γ < 0, і мінус на мінус дає плюс, тому c² > a² + b².

Трикутник — найстабільніша фігура в природі і архітектурі.
