ЧАСТИНА 1. ПОНЯТТЯ ФУНКЦІЇ

У математиці постійно з'являються залежності: одна величина змінюється — і друга теж. Функція — це спосіб таку залежність записати, дослідити і використати. У цій частині розберемо, що саме ми називаємо функцією, які терміни з нею пов'язані і як знаходити область визначення.

1. Від прикладу — до означення

Візьмемо знайому ситуацію. Протягом дня температура повітря змінюється:

Час (год)6:009:0012:0015:0018:0021:00
Температура (°C)121622242015

Що тут відбувається? Ми обираємо час (наприклад, 12:00) — і отримуємо рівно одну температуру (22°C). Не дві, не «невідомо» — одну конкретну. Час — це вхід, температура — вихід. І для кожного входу існує рівно один вихід.

Ось це і є функція.

Означення. Функція — це правило, за яким кожному допустимому значенню змінної x відповідає єдине значення змінної y. Записують: y = f(x).

Читається: «y дорівнює f від x» — тобто значення y залежить від того, яке x ми підставили.

2. Терміни — що як називається

Повернемося до прикладу з температурою і дамо кожній частині своє ім'я:

ТермінЩо цеУ нашому прикладі
Аргумент (x)Те, що ми обираємо самі — «вхід»Час: 6:00, 9:00, 12:00…
Значення функції (y)Те, що отримуємо у відповідь — «вихід»Температура: 12, 16, 22…
Область визначення D(f)Усі допустимі значення x — «які входи працюють»{6, 9, 12, 15, 18, 21}
Область значень E(f)Усі можливі значення y — «які виходи бувають»{12, 15, 16, 20, 22, 24}

Ще один приклад — формулою: y = x².

x−3−1013
y = x²91019

Зверніть увагу: x = −3 і x = 3 дають однаковий y = 9. Це нормально — різні входи можуть давати однаковий вихід. Головне правило функції: один вхід → рівно один вихід (а не навпаки).

D(f) = (−∞; +∞) — підставити можна будь-яке число. E(f) = [0; +∞) — квадрат будь-якого числа ≥ 0, від'ємних значень y не буває.

3. Графік функції — як читати

Графік — це усі точки (x; y) на координатній площині, де y = f(x). По горизонтальній осі відкладаємо x, по вертикальній — y. Кожна точка кривої каже: «при такому x функція дає ось такий y».

На графіку нижче позначено:

● чорні точки на осі xНулі функції — точки, де y = 0 (графік перетинає вісь x)
● кольорові точкиЕкстремуми — найвищі (max) та найнижчі (min) точки на ділянках графіка
↗ та ↘ під графікомЗростання і спадання — де функція йде вгору, а де вниз

4. Область визначення D(f) — де функція існує

Не для кожного x функція може видати відповідь. Спробуйте порахувати 1/0 або √(−4) на калькуляторі — він покаже помилку. Область визначення D(f) — це множина тих значень x, при яких вираз f(x) можна обчислити.

Три ситуації, коли виникають обмеження:

① Дріб — знаменник не може дорівнювати нулю.

f(x) = 1/(x − 3). Якщо x = 3, знаменник = 0 — ділити на нуль не можна. Тому D(f): x ≠ 3, або інакше: (−∞; 3) ∪ (3; +∞).

② Парний корінь — підкореневий вираз має бути ≥ 0.

f(x) = √(x − 1). Якщо x = 0, під коренем −1 — корінь з від'ємного числа в дійсних числах не існує. Потрібно: x − 1 ≥ 0 → x ≥ 1. D(f) = [1; +∞).

③ Логарифм — аргумент має бути строго > 0.

f(x) = log₂(x + 5). Потрібно: x + 5 > 0 → x > −5. D(f) = (−5; +∞). Зверніть увагу: саме >, а не ≥, бо log₂(0) не існує.

④ Комбінація — записуємо всі обмеження і шукаємо їх перетин.

Приклад. Знайти D(f) для f(x) = √(3 − x) / (x² − 4).

Тут є і корінь, і дріб — два обмеження одночасно:

  1. Корінь: 3 − x ≥ 0 → x ≤ 3
  2. Знаменник: x² − 4 ≠ 0 → (x − 2)(x + 2) ≠ 0 → x ≠ 2 та x ≠ −2
  3. Обидві умови мають виконуватися разом: x ≤ 3, але x ≠ 2 і x ≠ −2
  4. D(f) = (−∞; −2) ∪ (−2; 2) ∪ (2; 3]

Перевірка. Підставимо x = 0 (має входити): √3/(−4) — обчислюється ✓. Підставимо x = 2 (не входить): знаменник = 0 ✓. Підставимо x = 4 (не входить): √(−1) — не існує ✓.

5. D(f) і E(f) — як не плутати

Ці два терміни часто плутають, тому запам'ятайте просте правило:

D(f)Область визначенняЯкі x можна підставити?Дивимося по горизонтальній осі
E(f)Область значеньЯкі y функція може видати?Дивимося по вертикальній осі

Приклад: y = x². Підставити можна будь-яке x → D(f) = (−∞; +∞). А результат квадрата завжди ≥ 0, тому y не буває від'ємним → E(f) = [0; +∞).

Типові помилки

1. Плутають ≥ і > для кореня та логарифма.
Корінь: √0 = 0 — нуль дозволений, тому підкореневий вираз ≥ 0.
Логарифм: log(0) не існує, тому аргумент строго > 0.
Неправильно: D(f) для √x — пишуть x > 0. Правильно: x ≥ 0.

2. Забувають розкласти знаменник на множники.
f(x) = 1/(x² − 9). Пишуть «x ≠ 9». Але x² − 9 = (x − 3)(x + 3) = 0 при x = 3 і x = −3. Правильно: x ≠ 3 та x ≠ −3.

3. Плутають D(f) і E(f).
Для y = √x пишуть «E(f): x ≥ 0». Але x ≥ 0 — це D(f) (які x можна підставити). А E(f) — це про y: y ≥ 0, тобто [0; +∞).
