ЧАСТИНА 1. ВІДСТАНІ ТА СЕРЕДИНИ

Координатна геометрія — це спосіб розв'язувати геометричні задачі алгебраїчно: кожна фігура описується рівнянням, кожна відстань — формулою. Замість побудов — підстановка координат.

1. Основні формули для двох точок

Нехай A(x₁; y₁) і B(x₂; y₂) — дві точки на площині:

Відстань між точками|AB| = √((x₂−x₁)² + (y₂−y₁)²)Теорема Піфагора
Середина відрізкаM = ((x₁+x₂)/2; (y₁+y₂)/2)Середнє координат
Поділ у відношенні λ:1P = ((x₁+λx₂)/(1+λ); (y₁+λy₂)/(1+λ))λ=1 → середина

3. Взаємне розміщення двох прямих

Паралельніk₁ = k₂ (або A₁/A₂ = B₁/B₂ ≠ C₁/C₂)
Перпендикулярніk₁ · k₂ = −1 (або A₁A₂ + B₁B₂ = 0)
ЗбігаютьсяA₁/A₂ = B₁/B₂ = C₁/C₂
Перетинаютьсяk₁ ≠ k₂ → єдина спільна точка

Приклад: y = 2x + 1 і y = −½x + 3. k₁ · k₂ = 2 · (−½) = −1 → перпендикулярні ✓

4. Відстань від точки до прямої

d = |Ax₀ + By₀ + C| / √(A² + B²)

де (x₀; y₀) — точка, Ax + By + C = 0 — пряма

Приклад: відстань від точки (2; 3) до прямої 3x + 4y − 5 = 0:

d = |3·2 + 4·3 − 5| / √(9+16) = |6 + 12 − 5| / 5 = 13/5 = 2.6

Перевірка: знаменник √(A²+B²) = √25 = 5, чисельник = |13| = 13. d = 13/5 ✓

5. Кут між двома прямими

tg φ = |k₁ − k₂| / |1 + k₁·k₂|

При k₁·k₂ = −1 → перпендикулярні (φ = 90°). При k₁ = k₂ → паралельні (φ = 0°).

ЧАСТИНА 3. КОЛО ТА ІНШІ КРИВІ

6. Рівняння кола

(x − a)² + (y − b)² = R²

де (a; b) — центр, R — радіус

Спробуйте: рухайте центр і радіус:

Загальна форма: x² + y² + Dx + Ey + F = 0
Центр: (−D/2; −E/2). Радіус: R = √(D²/4 + E²/4 − F).
Приклад: x² + y² − 6x + 4y − 12 = 0 → центр (3; −2), R = √(9 + 4 + 12) = √25 = 5.

7. Взаємне розміщення прямої і кола

Обчислюємо відстань d від центра кола до прямої і порівнюємо з R:

d < RДва перетини (секуща)
d = RОдна точка (дотична)
d > RНе перетинаються

Типові помилки

1. Забувають модуль у формулі відстані точка–пряма.
d = |Ax₀+By₀+C|/√(A²+B²). Без модуля чисельник може бути від'ємним, а відстань — ні. Завжди беремо |...|!

2. Плутають рівняння кола і параболи.
(x−a)²+(y−b)² = R² — коло. y = a(x−h)²+k — парабола. Коло має x² і y² з однаковими коефіцієнтами. Парабола — тільки x² або тільки y².

3. Неправильно знаходять центр кола із загальної форми.
x²+y²+Dx+Ey+F=0 → центр (−D/2; −E/2), а не (−D; −E). Не забувайте ділити на 2!

4. Перпендикулярність: k₁·k₂ = −1, а не k₁·k₂ = 1.
Добуток нахилів перпендикулярних прямих = −1. Якщо k₁=2, то k₂ = −½, а не ½.
