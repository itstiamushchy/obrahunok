ЧАСТИНА 1. ЧИСЛОВІ ПОСЛІДОВНОСТІ

Послідовність — це список чисел за правилом: 1, ½, ⅓, ¼, … Ряд — це їхня сума: 1 + ½ + ⅓ + ¼ + … Головне питання: чи дає ця нескінченна сума скінченне число? Якщо так — ряд збігається. Це основа чисельних методів, фізики, інженерії — калькулятор обчислює sin x саме через ряди.

1. Поняття послідовності

Числова послідовність — впорядкований нескінченний набір чисел a₁, a₂, a₃, …, aₙ, … Кожен елемент aₙ задається формулою загального члена.

Загальний членФормула, що дає n-ий член: aₙ = f(n)
Приклад: aₙ = 1/n → 1, 1/2, 1/3, 1/4, …
Зростаючаaₙ₊₁ > aₙ для всіх n
Спаднаaₙ₊₁ < aₙ для всіх n
ОбмеженаІснують m і M: m ≤ aₙ ≤ M для всіх n
Монотонна + обмежена→ Обов'язково має границю (теорема Вейєрштраса)

2. Границя послідовності

Границя послідовності — число L, до якого «зближуються» члени при n→∞:

lim aₙ = L при n→∞

Збіжна послідовністьІснує скінченна границя L. Приклад: 1/n → 0
Розбіжна послідовністьГраниця або не існує, або нескінченна. Приклад: (−1)ⁿ коливається
Важливі границіlim n^(1/n) = 1
lim (1+1/n)ⁿ = e
lim n!/nⁿ = 0
lim xⁿ = 0 при |x|<1

ЧАСТИНА 2. ЧИСЛОВІ РЯДИ

3. Що таке числовий ряд?

Числовий ряд — сума нескінченної кількості чисел:

S = a₁ + a₂ + a₃ + … = Σ aₙ (n від 1 до ∞)

Часткова сума Sₙ = a₁ + a₂ + … + aₙ — це сума перших n членів. Ряд збігається, якщо часткові суми наближаються до якогось числа:

Збіжність: ряд збігається, якщо lim Sₙ = S (скінченне). Інакше — розбігається.

Практичний приклад: Ви стоїте за 1 метр від стіни і кожен крок — це половина залишеної відстані: ½ + ¼ + ⅛ + … Скільки всього пройдете? S = ½/(1−½) = 1 метр. Нескінченно кроків — але скінченна відстань!

! Необхідна умова збіжності

Якщо ряд збігається → lim aₙ = 0. Але зворотне невірно: lim aₙ=0 не гарантує збіжності!
Приклад: гармонічний ряд 1+1/2+1/3+… → lim 1/n=0, але ряд РОЗБІГАЄТЬСЯ!

4. Важливі ряди

Геометричний рядΣ qⁿ = 1/(1−q) при |q|<1
Розбігається при |q|≥1
Приклад: 1+1/2+1/4+… = 1/(1−1/2) = 2
Гармонічний рядΣ 1/n — РОЗБІГАЄТЬСЯ (незважаючи на aₙ→0)
Dовести: групуємо 1+1/2+(1/3+1/4)+(1/5..1/8)+… кожна дужка > 1/2
p-ряд Σ 1/nᵖЗбігається при p > 1
Розбігається при p ≤ 1
Приклад: Σ 1/n² = π²/6 (збігається); Σ 1/n (розбігається)

ЧАСТИНА 3. ОЗНАКИ ЗБІЖНОСТІ РЯДІВ

Рідко можна обчислити суму ряду напряму. Замість цього використовують ознаки — вони не дають саму суму, але відповідають: «збігається чи ні?». Ознаку обираємо за виглядом aₙ:

Що бачиш в aₙЯку ознаку
aₙ схожий на відомий ряд (1/nᵖ, qⁿ)Порівняння
Факторіал n! або степінь nⁿДаламбера (відношень)
aₙ = (f(n))ⁿ — все під n-ю степенемКоші (кореневий)
Знаки чергуються: +, −, +, −, …Лейбніца

5. Ознаки порівняння

Ознака порівняння (пряма)Якщо 0 ≤ aₙ ≤ bₙ для всіх n:
• Σbₙ збігається → Σaₙ збігається
• Σaₙ розбігається → Σbₙ розбігається
Гранична ознака порівнянняЯкщо lim aₙ/bₙ = L (скінченне, > 0), то Σaₙ і Σbₙ збігаються або розбігаються одночасно

6. Ознака Даламбера (відношень)

D = lim |aₙ₊₁/aₙ|

D < 1Ряд збігається абсолютноТипово для рядів з n! або nⁿ
D > 1Ряд розбігається—
D = 1Ознака не дає відповідіТреба інша ознака

Приклад: ряд Σ n/2ⁿ

aₙ = n/2ⁿ, aₙ₊₁ = (n+1)/2ⁿ⁺¹

D = lim aₙ₊₁/aₙ = lim (n+1)/(2ⁿ⁺¹) · 2ⁿ/n = lim (n+1)/(2n) = 1/2 < 1 → збігається

Перевірка інтуїцією: 1/2 + 2/4 + 3/8 + 4/16 + 5/32 + … = 0.5 + 0.5 + 0.375 + 0.25 + 0.156 + … — члени швидко зменшуються, сума прямує до 2.

7. Ознака Коші (кореневий критерій)

K = lim ⁿ√|aₙ|

K < 1Ряд збігається—
K > 1Ряд розбігається—
K = 1Ознака не дає відповіді—

8. Ознака Лейбніца (для знакозмінних рядів)

Знакозмінний ряд Σ (−1)ⁿ⁻¹·aₙ (aₙ > 0) збігається, якщо:

  • Послідовність {aₙ} є спадаючою: a₁ ≥ a₂ ≥ a₃ ≥ …
  • lim aₙ = 0

Приклад: Σ (−1)ⁿ/n = 1 − 1/2 + 1/3 − 1/4 + … = ln 2

aₙ=1/n: спадна ✓, lim 1/n=0 ✓ → збігається за ознакою Лейбніца

ЧАСТИНА 4. СТЕПЕНЕВІ РЯДИ І РЯД ТЕЙЛОРА

Степеневі ряди — це спосіб записати будь-яку «хорошу» функцію як нескінченний многочлен. Навіщо? Многочлени легко рахувати: тільки +, −, ×. Саме так калькулятор обчислює sin, cos, eˣ — додає перші кілька членів ряду.

9. Степеневий ряд

Степеневий ряд — ряд виду:

Σ cₙ·(x−a)ⁿ = c₀ + c₁(x−a) + c₂(x−a)² + …

Радіус збіжності R: ряд збігається при |x−a| < R, розбігається при |x−a| > R.

R = 1 / lim ⁿ√|cₙ| або R = lim |cₙ/cₙ₊₁|

10. Ряд Тейлора і Маклорена

Ряд Тейлора — розклад функції f(x) у степеневий ряд навколо точки a:

f(x) = Σ f⁽ⁿ⁾(a)/n! · (x−a)ⁿ

Ряд Маклорена: a = 0

f(x) = f(0) + f'(0)·x + f''(0)/2!·x² + …

11. Стандартні розклади (знати напам'ять)

Ці розклади — «паспорти» основних функцій. Найважливіший — eˣ, бо з нього виводяться інші:

ФункціяРозклад МаклоренаR

Практичний приклад: обчислити e¹ = e ≈ ? без калькулятора.

e = 1 + 1 + 1/2 + 1/6 + 1/24 + 1/120 + 1/720 + …

= 1 + 1 + 0.5 + 0.167 + 0.042 + 0.008 + 0.001 + … ≈ 2.718

Вже 7 членів дають точність 3 знаки! Ось чому ряди працюють.

Практичний приклад: sin(0.1) ≈ ?

sin(0.1) ≈ 0.1 − 0.1³/6 = 0.1 − 0.000167 ≈ 0.09983

Калькулятор: sin(0.1) = 0.09983… — два члени ряду дають 5 точних цифр!

Формула Ейлера (зв'язок e, π, i):

З розкладу eˣ при x=iφ: e^(iφ) = cos φ + i·sin φ
При φ=π: e^(iπ) + 1 = 0 — «найгарніша формула математики»

Алгоритм дослідження збіжності ряду

1. Необхідна умова: lim aₙ = 0? Якщо ні → ряд розбігається. Стоп.
2. Чи це відомий ряд? Геометричний (Σqⁿ) або p-ряд (Σ1/nᵖ)? Якщо так → відповідь відома.
3. Чи є n! або nⁿ? → Ознака Даламбера.
4. Чи є (…)ⁿ? → Ознака Коші.
5. Знаки чергуються? → Ознака Лейбніця.
6. Інакше → порівняння з відомим рядом.

Типові помилки

1. «lim aₙ = 0 → ряд збігається» — НЕ ВІРНО!
Це лише необхідна умова. Гармонічний ряд Σ1/n: lim 1/n = 0, але ряд розбігається. Необхідна ≠ достатня!

2. Плутають збіжність послідовності і ряду.
Послідовність 1/n → 0 (збігається). Ряд Σ1/n → ∞ (розбігається). Послідовність aₙ→0 — але їхня сума може бути нескінченною.

3. Забувають перевірити кінці інтервалу збіжності.
Степеневий ряд збігається при |x−a| < R. Але при |x−a| = R (кінці) — потрібна окрема перевірка підстановкою.

4. D = 1 — вважають, що ряд збігається.
Ознака Даламбера при D = 1 не дає відповіді! Потрібна інша ознака. Типова помилка: «D = 1 → на межі → збігається». Ні — «не знаємо».

5. Плутають ряд Маклорена sin x і cos x.
sin x — тільки непарні степені: x, x³, x⁵… cos x — тільки парні: 1, x², x⁴… Мнемоніка: sin(0)=0 → вільний член = 0 → починається з x. cos(0)=1 → починається з 1.

Ряди — нескінченність, яку можна зліпити в одне число.
